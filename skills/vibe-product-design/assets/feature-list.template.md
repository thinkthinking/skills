## Coding scheme
- **L1 Module** — 2–3 uppercase letters (e.g. `USR`, `PAY`), unique.
- **L2 Feature group** — `01–99`, related features grouped by business logic.
- **L3 Feature point** — `01–99`, a complete independent unit of functionality.
- **L4 Sub-feature** — `01–99`, smallest unit, written as a user story.
- Full ID example: `PAY-02-03-01`.

## Legends
- **优先级:** P0 must · P1 should · P2 could · P3 later
- **预估工作量:** XXS 1–2d · XS 3–5d · S 1–2w · M 2–4w · L 1–2mo · XL 2–3mo · XXL 3mo+
- **技术复杂度:** Low · Medium · High · Very High

## L4 user-story format
```
作为 [角色]
我想要 [功能]
以便于 [价值]
```
