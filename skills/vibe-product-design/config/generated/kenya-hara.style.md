# 风格：原研哉 / 无印良品（MUJI）极简

高保真 UI 设计稿（非线框图、非灰框占位），锚定原研哉（Kenya Hara）/ 无印良品（MUJI）的极简设计
语言：极致克制、大面积留白、安静内敛，让信息层级凭借留白与对齐自己浮现，而不是靠装饰堆砌。配色
用温润的米白 / 象牙白背景（约 #F7F5F0），近黑的深灰正文（约 #2B2B2B），浅灰做分隔，至多一种低
饱和自然色点缀（陶土、灰蓝或苔绿一类）；规避高饱和亮色、炫彩渐变。字体用纤细的现代无衬线中文字体
（类思源黑体 / 苹方），字重偏轻，字号层级克制而清晰。布局讲究大面积负空间与呼吸感，宁少勿满，网格
对齐严整、主次分明，关键操作靠位置与留白强调，而非大色块。组件为细描边、极浅阴影或无阴影、柔和
圆角，无拟物质感、无多余图标装饰、无营销风插画。整体氛围安静、内敛、有呼吸感。

界面必须使用真实文案与内容（真实标题、按钮文字、数据、列表项），不要占位框、假字或乱码；把这个
界面最关键的设计决策清楚展现出来——核心组件的形态、信息层级、以及此刻所处的交互状态。同一功能的
不同状态（默认 / 选中 / 空 / 加载 / 异常）各出一张图，用状态差异体现设计，不要把多个状态挤进一张图。
