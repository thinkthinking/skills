# Codex CLI 0.135.0（中文版）

## 新功能
- `codex doctor` 现在会报告更丰富的环境、Git、终端、app-server 和 thread inventory 诊断信息，方便支持场景排查。(#24261, #24311, #24305)
- 当 TUI 通过远程传输连接时，`/status` 会显示远程连接详情和服务器版本。(#24420)
- Vim mode 新增了 text-object 编辑，改进了单词/行尾行为，并支持可配置的 interrupt-turn 绑定。(#24382, #24380, #24766)
- `/permissions` 现在支持命名权限配置文件，并会显示已配置的自定义配置文件。(#21559)
- 打包版 Codex 构建可以在受支持的 macOS 和 Linux 目标上发现并使用内置的 patched zsh helper。(#23756, #24171)
- Python SDK 现在为 thread 和 turn API 暴露了更友好的 `Sandbox` 预设。(#24772)
- 当设置 `CODEX_NON_INTERACTIVE=1` 时，`install.sh`/`install.ps1` 支持非交互式安装模式。(#21567)

## 修复
- Markdown 表格和多行列表在 TUI 中的渲染更易读，列宽分配和 app-style table formatting 得到改进。(#24489, #24346, #24351)
- TUI 在 macOS 和 Zellij 上的输出更稳定，避免 stderr/composer 被污染以及 raw-output 重叠。(#24459, #24479, #24593)
- Slash-command 补全现在会为接受 inline arguments 的命令保留已有草稿文本。(#23950)
- 较旧的 tmux/iTerm control-mode 会话不再因不支持的 keyboard enhancement 设置而丢失正常的 `Ctrl-C` 处理。(#24371)
- App mentions 现在会排除无法访问或已禁用的 apps，避免提供不可用的 `$` 建议。(#24625)
- Resume 流程现在会在请求时包含 non-interactive exec sessions，并且会为 idle cached threads 遵循 cwd overrides。(#24503, #24528)

## 文档
- 澄清了 image-viewing tool detail 行为，并移除了过时的 TUI composer 文档引用。(#23949, #24641)
- 更新了 Python SDK 文档、示例和 notebook 内容，以使用新的 sandbox preset API。(#24772)

## 日常维护
- 更新了 Rust toolchain pins 以及 SQLx/SQLite 依赖。(#24684, #24728)
- 将 memory runtime state 迁移到专用的 SQLite 数据库。(#24591)
- 移除了剩余的 legacy config-profile consumers，并将更多 TUI config/plugin state 路由到 app-server-owned APIs。(#24076, #24254, #24255, #24265, #24266, #24257)
- 集中处理 Responses retry handling 和 MCP tool naming logic，减少重复的内部 plumbing。(#24131, #21576)
