# Codex 0.130.0（中文版）

## 新功能
- Plugin details 现在会显示 bundled hooks，plugin sharing 也会暴露 link metadata 和 discoverability controls。（#21447, #21495, #21637）
- 新增 `codex remote-control`，作为启动 headless、可远程控制 app-server 的更简单入口。（#21424）
- App-server clients 现在可以使用 unloaded、summary 或 full turn item views 对大型 threads 分页。（#21566）
- Bedrock auth 现在可以使用来自 `aws login` profiles 的 AWS console-login credentials。（#21623）
- `view_image` 可以通过所选 environment 解析文件，支持 multi-environment sessions。（#21143）

## 修复
- Live app-server threads 现在无需重启即可获取 config changes。（#21187）
- Turn diffs 在 apply-patch operations 中会保持准确，包括 partial failures 但文件已经发生变更的情况。（#21180, #21518）
- Thread summaries、renames、resume 和 fork paths 通过 `ThreadStore` 工作得更好，包括没有 local rollout paths 的 threads。（#21264, #21265, #21266）
- Remote compaction 现在会为 v2 streams 发出 `response.processed`，并避免在 API-key compact requests 上发送 `service_tier`。（#21642, #21676）
- Windows sandbox setup 现在会授予 sandbox users 访问 desktop runtime binary cache 的权限。（#21564）
- 移除了 `codex exec` startup banner 中过时的“research preview”措辞。（#21683）

## 文档
- 修复了 issue templates，让 CLI reports 保留预期 guidance，labels 正确应用，feature requests 链接到正确的 contributing docs。（#21685, #21686, #21688）
- 更新 install 和 tooling docs，统一使用 `cargo install --locked`。（#21592）

## 杂项
- 新增更快的 Cargo profiling build profile，并禁用 empty doctest targets，以加速 Rust development loops。（#21574, #21584）
- 通过 fully qualified GitHub Action pins、Dependabot cooldown 和 `cargo-shear` upgrade 强化 dependency 与 CI hygiene。（#21436, #21547, #21599）
- 移除了 unused device-key APIs、extra skills roots、remote thread-store implementation 和 string-keyed MCP tool maps，简化 internal surfaces。（#21487, #21485, #21596, #21454）
- 新增 configurable OpenTelemetry trace metadata，以及更丰富的 review/feedback analytics，便于 debugging 和 triage。（#21556, #18747, #21434, #21498）
