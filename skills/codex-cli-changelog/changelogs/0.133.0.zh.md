# Codex CLI 0.133.0（中文版）

## 新功能
- Goals 现在默认启用，由专用存储支撑，并会跨 active turns 跟踪进度。（#23300, #23685, #23696, #23732）
- `codex remote-control` 现在会像前台命令一样运行，等待 readiness、报告 machine status，并保留显式 daemon-style `start`/`stop` commands。（#22878）
- Permission profiles 新增 list APIs、inheritance、managed `requirements.toml` 支持、runtime refresh behavior，以及更强的 Windows sandbox integration。（#22928, #23412, #22270, #23433, #22931, #23715）
- Plugin discovery 更容易检查：list output 现在具备 marketplace awareness，会显示 installed versions、可见的 marketplace roots，并支持 remote collection。（#23372, #23584, #23727, #23730）
- Extensions 现在可以观察更多 lifecycle events，包括 subagent start/stop、tool execution、turn metadata，以及 async approval/turn processing。（#22782, #22873, #23309, #23688, #23690, #23692）

## 修复
- 修复了复用 local app-server socket 时，TUI startup 选择错误 working directory 的问题。（#23538）
- 修复了 plan-mode free-form answers：经过修改的 Enter keys（例如 Shift+Enter）不会再意外 submit。（#23536）
- 移除了 process exits 后残留的 background terminal poll events。（#23231）
- 除非明确请求 output token limit，否则会保留原始 code-mode exec output。（#23564）
- AGENTS instruction loading 更可靠了，包括 local global reads，以及对 invalid UTF-8 发出 warnings，而不是静默丢弃。（#23343, #23232）
- 修复了 app-server startup/shutdown races、空的 resume/fork paths、plugin upgrade failures，以及 realtime v1 websocket compatibility 问题。（#23516, #23578, #23400, #23356, #23771）

## 文档
- 新增了更清晰的 plugin-creator guidance，用于更新和重新安装 local personal plugins。（#23542）
- 扩展了围绕 managed permission profile requirements 的 app-server/API docs 和 schema coverage。（#23433, #23555）

## 维护
- 新增 canonical Codex package archive pipeline，并将 installers、npm packages、DotSlash 和 SDK runtimes 迁移到这个 shared layout。（#23513, #23582, #23586, #23596, #23635, #23636, #23637, #23638, #23786）
- 修复了 Linux Python runtime wheel tags，使 glibc-based systems 可以安装 runtime artifacts。（#21812）
- 通过 package-builder tests、prebuilt resource packaging、DotSlash zstd handling、platform-sharded Rust tests 和 Codex Linux release runners，提升 release 与 CI reliability。（#23760, #23759, #23752, #23358, #23761）
