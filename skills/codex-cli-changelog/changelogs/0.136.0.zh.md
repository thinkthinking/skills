# Codex CLI 0.136.0（中文版）

## 新功能

- TUI 的 markdown 现在会通过 OSC 8 元数据保持网页链接可点击，过于拥挤的表格会切换为更易读的键/值记录，且不丢失链接目标。(#24472, #24636, #24825)
- 现在可以从 TUI 用 `/archive` 或从 CLI 用 `codex archive` / `codex unarchive` 归档会话；归档后的会话在恢复前不可被 resume/fork。(#25027, #25021)
- App-server 集成现在可以携带初始轮次页面恢复线程、查看更丰富的 MCP server 状态，并通过 `codex app-server --stdio` 启动 stdio 模式。(#23534, #24698, #24940)
- 远程执行配置现在支持为已批准的 OpenAI 主机进行 `CODEX_API_KEY` 注册，同时远程控制的 websocket 改用短时效的服务端 token，而非 ChatGPT 访问 token。(#24666, #24141)
- Windows 管理员可使用 alpha 版的 `codex sandbox setup --elevated` 预置流程，并新增对允许的 Windows sandbox 实现的 requirements 支持。(#24831, #23766)
- 受 feature 开关控制的独立图像生成扩展现在可以通过原生 Codex 图像产物补全管线运行。(#24723, #24972)

## 问题修复

- ChatGPT 认证现在会在 token 五分钟过期窗口前刷新，并对被重复使用的 refresh token 显示需要重新登录的路径，而不再退化为通用云端错误。(#23546, #24830)
- 命令安全加固防止 `/diff` 运行仓库提供的 Git helper/hook，避免在非 Windows 主机上执行 PowerShell 解析器，并拒绝来自浏览器来源的 exec-server websocket 握手。(#24954, #24946, #24947)
- Sandbox 命令在中断或被拒绝的 Windows 网络尝试后能更可靠地清理，且 `deny` 读取规则在 safe-command 和 approval-bypass 路径下持续生效。(#22729, #19880, #23943)
- 恢复的 TUI 会话会从会话 transcript 种入 prompt 历史，多行 hook 输出会渲染为独立行，Vim 普通模式编辑行为也已恢复正确。(#24298, #24965, #25022)
- App-server 文件系统 watcher 现在能正确对后续批次去抖，独立的 web search 调用现在会显示并恢复已完成的搜索活动。(#24716, #24693)
- Bedrock 认证现在会回退到 `AWS_REGION` / `AWS_DEFAULT_REGION`，且不再宣告或发送不受支持的 Bedrock GPT 服务层级。(#25171, #25318)

## 文档

- Python SDK beta 文档与包元数据现在提供标准的 `pip install openai-codex` 安装路径，并更新了快速上手、API 参考、FAQ 和示例。(#24836, #24866, #24868, #24870)
- Python SDK 示例与文档现在使用公开的 `CodexConfig` 名称来配置 `Codex` / `AsyncCodex`。(#24800)
- 内置的 OpenAI Docs skill 已更新，纳入当前的 Codex 手动路由和一个带缓存的手册抓取 helper。(#24914)
- 内置工具的 schema 描述现在在 shell、Code Mode、MCP、image、goal、plan、multi-agent 等相关工具中阐明了默认值、可选字段、取值范围和枚举。(#24794)
- App-server 与 exec-server 文档现在涵盖 API key 远程注册、`--stdio`、运行时额外 skill 根目录，以及远程控制的服务端 token 行为。(#24666, #24940, #24977, #24141)

## 杂项

- Python SDK 发布现在可以使用 `python-v*` 标签独立于运行时发布进行预备和发布，同时保留经过审查的运行时依赖固定版本。(#24828, #24872)
- 将 MCP 依赖更新至 `rmcp` 1.7.0 并刷新了兼容性代码。(#24763)
- 刷新了 Amazon Bedrock 目录元数据，包括 GPT-5.5、移除不受支持的 OSS 条目，以及 GPT 模型仅默认层级的行为。(#24701, #24960, #25318)
- 移除了陈旧的 app-server debug-client 部件并在删除后清理了工作区。(#25063, #25064, #25065, #25066, #25067, #25068, #25069, #25070, #25075)
- 精简了 CI/构建维护：将 Bazel Windows 任务迁移到 Codex runner、移除 libubsan 临时方案，并回退了导致 musl 构建器失败的启动基准测试。(#24952, #24782, #24937)
