# Codex CLI 0.134.0（中文版）

## 新功能
- 新增本地对话历史搜索，支持不区分大小写的内容匹配和结果预览。 (#23519, #23921)
- 将 `--profile` 作为 CLI、TUI 权限和 sandbox 流程中的主要 profile 选择器，并通过迁移指引拒绝旧版 profile 配置。 (#23708, #23883, #23890, #24051, #24055, #24059, #24067, #24110)
- 优化 MCP 设置，支持按服务器指定环境，并为 streamable HTTP 服务器提供 OAuth 选项。 (#23583, #24120)
- 通过保留本地 `$ref`/`$defs` 结构，并在暴露前压缩过大的 schema，让 connector tool schema 更可靠。 (#23357, #23904)
- 当只读 MCP tool 声明 `readOnlyHint` 时，允许它们并发运行。 (#23750)
- 新增更丰富的 extension 和 hook 上下文，包括 extension tools 可访问的对话历史，以及 hook 输入中的 subagent 身份。 (#22882, #23963)

## 修复
- 通过重连过期的 exec-server websocket 客户端、在认证恢复后立即重试 remote control，以及重试 remote compaction v2 streams，提升 remote 可靠性。 (#23867, #23775, #23951)
- 通过在绘制前恢复 virtual terminal mode，修复 Windows TUI 渲染损坏。 (#24082)
- 针对 credit 和 spend-cap 失败，展示 workspace-specific 的使用限制提示。 (#24114)
- 允许 plugin skills 复用共享的 plugin-level icon assets。 (#23776)
- 同步 auto-review runtime settings 时，保留当前有效的 permission profile metadata。 (#23956)
- 确保基于 Node 的 tools 遵循 Codex 托管的 network proxy environment。 (#23905)

## 文档
- 在 README 中记录 curl 和 PowerShell 安装路径。 (#24106)
- 更新开发者文档，建议在 repo-local test runs 中优先使用 `just test`，而不是直接运行 `cargo test`。 (#23910)
- 在相关 config 错误中新增 profile migration documentation links。 (#23879)

## 杂项
- 围绕 canonical native artifacts、可复用的 DotSlash fetching，以及新的 macOS x64 zsh artifact，简化 release packaging。 (#23833, #23836, #24129, #24165)
- 新增对 Codex 产出的 V8 artifacts 的 release-build 支持。 (#23934)
- 新增 image re-encoding benchmarks 和 connector-style JSON schema policy fixtures。 (#23935, #24152)
- 优化 websocket requests、turn starts 和 remote compaction v2 的 tracing 与 analytics。 (#23581, #23980, #24146)
