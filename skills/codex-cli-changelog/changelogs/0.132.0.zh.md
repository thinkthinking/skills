# Codex 0.132.0（中文版）

## 新功能
- Python SDK 现在支持一等 authentication，包括 API key login、ChatGPT browser 和 device-code flows、account inspection，以及 logout APIs。（#23093）
- Python turn APIs 对 text-only workflows 更容易使用：可以直接传入 plain string 作为 input，基于 handle 的 runs 现在会返回更丰富的 `TurnResult`，包含 collected items、timing 和 usage data。（#23151, #23162）
- `codex exec resume` 现在接受 `--output-schema`，因此恢复的 automations 可以保留 session context，同时继续强制执行 structured JSON output。（#23123）
- TUI 启动更快了，因为 terminal capability probes 现在会批量执行，不再在首个 interactive frame 之前等待多个串行 checks。（#23175）
- Remote executor registration 现在可以使用标准 Codex auth，而不需要单独的 registry credential flow。（#22769）
- App-server turns 现在可以在 user inputs 和 image-producing tools 之间保留请求的 image fidelity，包括 original-resolution local images。（#20693）

## Bug 修复
- Goal continuations 现在会在触及 usage limits 或 repeated blocker 时停止，避免继续循环并消耗更多 tokens；completion responses 对 usage 的表述也更自然。（#23094, #22907）
- Session picker 更值得信赖：重命名后的 threads 现在会在 resume hints 中显示 `name (thread-id)`，并且粘贴文本可以在 picker search box 中正常工作。（#23234, #23338）
- Multi-session TUI flows 更可靠了：replay 期间 in-progress MCP calls 会保持 active 标记，elicitation replies 也会发送回发起请求的 thread。（#23236, #23241）
- Remote sessions 现在会保持 websocket connections alive，并重新显示 repo-relative diff paths，而不是带有 `/tmp/...` 前缀的 paths。（#23226, #23261）
- Windows installs 更稳健了：`codex doctor` 现在能正确检测 npm-managed installs，MSVC release binaries 也不再依赖单独安装的 VC++ runtime DLLs。（#22967, #22905）
- TUI polish 修复包括：退出时立即显示 shutdown feedback、为非 OpenAI providers 隐藏 ChatGPT usage link，以及避免已清除的 Fast tier 在 side-thread resume 后重新出现。（#23323, #23127, #23121）

## 文档
- Python SDK docs、FAQ 和 examples 围绕新的 auth flow 与 turn APIs 做了刷新，提供更清晰的 setup guidance 和更简单的 text-only examples。（#22941, #23093, #23151, #23162）

## Chores
- Memory summaries 现在会 versioned，并在 stored format 过期时重建，这应该能让 long-lived memory context 更精简、更可预测。（#23148）
