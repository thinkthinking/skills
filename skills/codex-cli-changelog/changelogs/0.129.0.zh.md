# Codex 0.129.0（中文版）

## 新功能
- TUI 现在支持 composer 中的 Vim 模态编辑，包括 `/vim`、默认模式配置，以及 Vim 专用 keymap contexts。（#18595）
- 重新设计的 resume/fork picker、raw scrollback mode、`/ide` context injection，以及 workspace-aware `/diff` 让 TUI 工作流更容易恢复和复制。（#20065, #20819, #20294, #21001）
- status line 可以显示 theme-aware colors，以及可选的 PR 和 branch-change 摘要；`/keymap debug` 可用于检查 terminal key events。（#19631, #20892, #20794）
- 插件管理现在支持 workspace sharing、share access controls、source filtering、local share path tracking、marketplace removal/upgrades、remote bundle sync，以及 admin-disabled 状态处理。（#20278, #21124, #21419, #20560, #19843, #20478, #20268, #20298）
- Hooks 可以从 `/hooks` 浏览和切换，可以在 compaction 前后运行，也可以添加 `PreToolUse` context；Codex Apps auth 和符合条件的 MCP elicitations 现在会通过 TUI/Guardian flows 显示。（#19882, #19905, #20692, #19193, #19431）
- Experimental goals 现在可被发现，恢复会话后会保持暂停，除非用户主动重新启用，并提供更清晰的验证和 multi-day duration 输出。（#20083, #20790, #20746, #20558）

## Bug 修复
- `/copy` 在 tmux 中表现更好，Alt+Enter 和带修饰键的 Delete/Backspace 行为更正确，并降低了 Windows 输入/粘贴延迟。（#20207, #20535, #21058, #18914）
- 大段粘贴占位符和 Ctrl+C 暂存的 drafts 现在可以在 clear/editor 工作流后保留，不会破坏 draft history。（#21091, #21190, #21351, #21397）
- 通过限制 terminal probes、清除第一次 inline viewport render，并在 live rows 中遵守 `animations = false`，TUI 启动和无障碍体验更加稳健。（#20654, #21450, #20564）
- Linux sandbox 启动在较旧的 `bwrap`、慢 mount probes、受 symlink 保护的路径，以及共享 `/tmp` 设置下更可靠。（#20628, #20111, #21127, #21234）
- Windows sandbox 和 exec policy 现在能更可靠地处理 named pipes、ConPTY teardown、PowerShell-wrapped allow rules、worktree `safe.directory`，以及不安全的 Git options。（#20270, #20685, #20336, #21409, #21275）
- 修复了 TLS-inspecting proxies 后的 custom CA login、Bedrock runtime endpoint reporting、危险的 project config keys、heredoc redirect approval matching，以及无边界增长的 MCP/hook output。（#20676, #20275, #20098, #20113, #20260, #21069）

## 文档
- 更新了内置 OpenAI Docs sample skill，使 API-key setup guidance 与其他 docs variants 保持一致。（#21263）
- 记录了 generated git commit attribution 如何由 `codex_git_commit` gating，并在 `config.toml` 中配置。（#21379）
- 移除了 local-only planning/spec docs，并将 config docs 指向维护中的 external documentation surface。（#20896）

## Chores
- Linux releases 现在会为 npm 和 DotSlash installs 构建、发布、打包并验证 standalone `bwrap` fallback。（#21255, #21256, #21257, #21312, #21285）
- Vendored Bubblewrap 更新到 0.11.2，包含 upstream 关于 setuid support 的安全变更。（#21389）
- Windows Bazel CI 现在对 tests、clippy 和 release-build checks 使用更快的 cross-compilation；Bazel 现在也会运行 sharded Rust integration tests。（#20585, #20701, #21057）
- app-server 和 protocol internals 被拆分并精简，包括 transport extraction、protocol module decomposition、thread/message history moves，以及 tool-handler cleanup。（#20324, #20325, #20348, #20545, #21251, #21278, #21395）
- Analytics 和 diagnostics 覆盖范围扩展到 tool lifecycles、goals、plugin skills、thread sources、service tiers，以及 PR issue labeling。（#17089, #17090, #20799, #20923, #20949, #20969, #20893）
