# Codex App 26.519（中文版）

## Appshots、Goal mode 等更新 26.519

Appshots 现已在 macOS 版 Codex app 中可用。按下两个 Command 键，即可将最前方的 app 窗口连同截图和可用文本发送给 Codex，让 Codex 能基于另一个 app 中的上下文工作，而无需你手动复制、粘贴或描述。

本次发布还包括：

- Goal mode 不再是实验性功能，并已在 Codex app、IDE extension 和 CLI 中可用。借助 Goal mode，你可以让 Codex 围绕特定目标持续推进数小时，甚至数天。
- Remote computer use，让 Codex 可以在你的 Mac 锁定后继续使用桌面 app，也包括通过 Codex Mobile 远程使用。Codex 会将锁定状态下的使用限制在活跃且可信的 computer use 回合中，并包含短期授权、遮盖显示内容、本地输入后重新锁定、以及手动解锁回退等保护措施。
- ChatGPT Business 现已支持通过 marketplace sources 分享插件。Enterprise 支持即将推出。团队可以分发可复用的 plugin bundles，其中包含 skills、app integrations、MCP servers 和 lifecycle hooks。
- Advanced in-app browser annotations 可让你直接使用 annotations 微调字体大小、颜色和间距等样式。这会为 Codex 提供更清晰的修改信号。
- Codex 现在可以更快地从页面下载并提取所有图片资产。
- 借助只读 JS sandbox，Codex 现在可以更有效地从页面提取结构化数据，并更快找到信息。

- 使用 Chrome extension 时产生的杂乱内容会更少。Codex 在接管现有标签页以及任务结束交接时，将不再创建 tab groups，而是使用标签页图标来标示状态。
- 显著提升了 browser use 的可靠性。我们修复了 Windows 上的问题、插件在非地理封锁区域可用性不稳定的问题，以及许多其他影响性能的问题。
