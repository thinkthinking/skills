# Codex App 26.527（中文版）

## Windows 上的 Computer use 与移动端访问 26.527

## 新功能

- Computer Use 现已支持 Windows。Codex 可以在工作时通过观察、点击和输入来操作前台的 Windows 桌面应用。
- Remote control 现已支持 Windows 设备。你可以从 iOS 或 Android 上的 ChatGPT、或从运行 Codex 的 Mac 上启动 Windows 设备上的 Codex 工作，并远程查看进度。
- Profile 区域现在会显示你的个人资料详情、用量统计和 token 活动。
- 新增了对本地项目和 worktree 的线程协调，包括在明确请求时启用独立的后台线程。
- 扩展了对过往 Codex app 线程的搜索，现在可涵盖对话内容和 Git 分支名。
