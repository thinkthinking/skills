# Vibe Writing Onboarding

Use this only when memory is sparse or the user explicitly wants a better
writing companion profile. Do not derail an active writing flow.

## If The User Knows Their MBTI

Ask:

1. "你愿意把这个 MBTI 当成冷启动假设吗？后面我会根据你的真实写作选择修正它。"
2. "你希望我更像编辑、辩友、灵感搭子、结构顾问，还是混合一点？"
3. "你最不希望 AI 在你的文章里做什么？"

Record:

- `identity.mbti.self_reported`
- `mirror.mbti.type`
- `mirror.strategy.initial`
- any explicit collaboration preferences

## If The User Does Not Know Their MBTI

Ask 6-8 of these, adapted to the moment:

1. 写作刚开始时，你更需要发散灵感，还是帮你收束成一个核心判断？
2. 你更容易写出情绪和感受，还是结构和论点？
3. 你喜欢 AI 直接挑战你，还是先共情再提出异议？
4. 修改文章时，你最在意锋利、准确、自然、节奏，还是完整？
5. 你讨厌哪类 AI 写作痕迹？
6. 你希望我多问问题，还是多给候选表达？
7. 你更想要读者被说服、被触动、被启发，还是被带着一起思考？
8. 当我觉得你的观点还不够成立时，你希望我直接指出，还是用问题带你看到？
9. 你喜欢保留口语感，还是希望成稿更克制、完整、可发布？
10. 有没有一位作者、博主或作品，是你希望我理解但不要机械模仿的？

Convert answers into tentative records such as:

- `style.prefer.*`
- `style.avoid.*`
- `collaboration.prefer.*`
- `collaboration.avoid.*`
- `mirror.strategy.initial`
