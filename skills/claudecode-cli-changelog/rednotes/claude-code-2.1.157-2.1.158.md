# Claude Code 2.1.157-2.1.158｜插件不用 marketplace 了，worktree 还能中途切

Claude Code 这两版最实用的改动是：`.claude/skills` 目录下的插件现在直接自动加载，不再需要挂 marketplace，配上新的 `claude plugin init` 脚手架，本地造插件这条路顺多了；再加上 `EnterWorktree` 支持会话中途切换 worktree、以及一大票后台 agent、resume 和终端渲染的修复，属于把上个大版本（Opus 4.8 + 动态 workflow）铺好的地基继续夯实的一次更新。最新的 2.1.158 则给 Bedrock/Vertex/Foundry 上的 Opus 4.7/4.8 补上了 Auto 模式。
