Claude Code 2.1.139 这版重点看两个新能力：Agent View 可以用一个列表看清所有 Claude Code 会话，哪些正在跑、哪些等你处理、哪些已经完成，运行 `claude agents` 就能开始用；新的 `/goal` 则可以给 Claude 设置完成条件，让它跨多个回合持续推进，直到目标达成，并在浮层里实时显示耗时、回合数和 token 数。多任务、长会话、远程控制这些场景会明显更顺手。
