# Claude Code 2.1.129（中文版）

- 新增 `--plugin-url <url>` 参数，可从 URL 拉取插件 `.zip` 包并在当前会话中加载
- 新增 `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` 环境变量，可在自动检测失效的终端（例如 Emacs 的 `eat`）上强制启用同步输出
- 新增 `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`：在 Homebrew 或 WinGet 安装环境下设置后，Claude Code 会在后台执行升级命令并提示用户重启
- 插件清单：`themes` 与 `monitors` 改为应在 `"experimental": { ... }` 节点下声明。顶层声明仍然可用，但 `claude plugin validate` 会发出警告
- `/model` 选择器中的网关 `/v1/models` 发现机制改为可选项，需通过 `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` 显式开启（在 2.1.126–2.1.128 中曾默认开启）
- Ctrl+R 历史记录选择器恢复为默认跨所有项目搜索全部 prompt，与 2.1.124 之前的行为一致。按 Ctrl+S 可收窄到当前项目或当前会话
- 第三方部署（Bedrock、Vertex、Foundry 或 `ANTHROPIC_BASE_URL` 网关）不再看到指向 Anthropic 第一方界面的 spinner 提示语
- `skillOverrides` 配置现已生效：`off` 同时对模型和 `/` 隐藏；`user-invocable-only` 仅对模型隐藏；`name-only` 折叠 description
- OTel 指标 `claude_code.pull_request.count` 现在会统计通过 MCP 工具创建的 PR/MR，不再只统计 shell 命令
- 策略拒绝错误信息中现已包含 API Request ID，便于排障与支持沟通
- 修复：未识别的 400 状态码错误会显示原始 JSON，而非底层报错信息
- 修复：`/clear` 不会重置会话结束后的终端标签页标题
- 修复：来自 `/rename` 的会话标题徽标在权限或其他对话框激活时消失
- 修复：subagent 运行期间，prompt 下方的 agent 面板被隐藏（2.1.122 引入的回归）
- 修复：外部编辑器跳转（Ctrl+G）会清空 prompt 上方的对话历史
- 修复：`/context` 会把渲染好的 ASCII 可视化网格直接倾倒进对话，每次浪费约 1.6k token
- 修复：`/agents` 库列表的方向键导航——当列表超出视口高度时，高亮项现在能始终保持可见
- 修复：`/branch` 的成功提示未带上可供 `/resume` 使用的新分支 session id
- 修复：在全屏模式下，含 keycap、ZWJ 或肤色 emoji 的加粗标题会丢失尾部字符
- 修复：企业/团队用户存储的 OAuth 凭据若缺少 `user:inference` scope，由服务端下发的 settings 策略未能生效
- 修复：从睡眠唤醒后的 OAuth 刷新竞态可能导致所有运行中的会话被踢下线
- 修复：1 小时 prompt cache TTL 被静默降级为 5 分钟
- 修复：在 `/clear` 或 compact 之后切换 `/effort` 或 `/model` 时，错误地弹出 cache-miss 警告
- 修复：`Bash(mkdir *)`、`Bash(touch *)` 等 allow 规则对项目内路径未生效
- 修复：`deniedMcpServers` 中带 `*://` 协议通配的规则无法匹配大小写混用的主机名
- 修复：voice 模式下，无害的 WebSocket 警告在 `--debug` 中被错误地按 error 级别打印
- [VSCode] 修复：`/clear` 未清空会话上下文与显示的 transcript
