# Claude Code 2.1.118（中文版）

- 新增 vim 视觉模式（`v`）和视觉行模式（`V`），支持选区、操作符和视觉反馈
- 将 `/cost` 与 `/stats` 合并为 `/usage`，两者仍可作为输入快捷方式分别打开对应标签页
- 可在 `/theme` 中创建并切换命名的自定义主题，或直接手动编辑 `~/.claude/themes/` 下的 JSON 文件；插件也可通过 `themes/` 目录附带主题
- Hooks 现可通过 `type: "mcp_tool"` 直接调用 MCP 工具
- 新增 `DISABLE_UPDATES` 环境变量，彻底禁用所有更新路径（包括手动 `claude update`),比 `DISABLE_AUTOUPDATER` 更严格
- Windows 上的 WSL 现可通过 `wslInheritsWindowsSettings` 策略键继承 Windows 端的托管设置
- 自动模式：在 `autoMode.allow`、`autoMode.soft_deny` 或 `autoMode.environment` 中加入 `"$defaults"`，即可在内置规则之外追加自定义规则，而不是整体覆盖
- 自动模式启用提示中新增「不再询问」选项
- 新增 `claude plugin tag`，用于为插件创建发布 git 标签，并带版本号校验
- `--continue`/`--resume` 现在能找到通过 `/add-dir` 添加了当前目录的会话
- 当 Remote Control 已连接时，`/color` 会将会话强调色同步到 claude.ai/code
- 在使用自定义 `ANTHROPIC_BASE_URL` 网关时，`/model` 选择器会遵守 `ANTHROPIC_DEFAULT_*_MODEL_NAME`/`_DESCRIPTION` 覆盖
- 当自动更新因另一个插件的版本约束而跳过某插件时,跳过记录会出现在 `/doctor` 和 `/plugin` 的 Errors 标签页中
- 修复 `/mcp` 菜单对使用 `headersHelper` 配置的服务器隐藏 OAuth 认证/重新认证操作的问题,以及带自定义 header 的 HTTP/SSE MCP 服务器在一次瞬时 401 后被卡在「需要认证」状态的问题
- 修复 OAuth token 响应中缺少 `expires_in` 字段的 MCP 服务器每小时都需要重新认证的问题
- 修复当服务器返回 `insufficient_scope` 403 且所列 scope 是当前 token 已拥有时,MCP 提权授权静默刷新而不是提示重新同意的问题
- 修复 MCP 服务器 OAuth 流程超时或被取消时抛出未处理 promise rejection 的问题
- 修复 MCP OAuth 刷新在高并发下未走跨进程锁的问题
- 修复 macOS 钥匙串竞态:并发的 MCP token 刷新可能覆盖刚刚刷新过的 OAuth token,导致意外出现「Please run /login」提示
- 修复当服务器在本地过期时间之前吊销 token 时 OAuth 刷新失败的问题
- 修复 Linux/Windows 上凭证保存崩溃导致 `~/.claude/.credentials.json` 损坏的问题
- 修复通过 `CLAUDE_CODE_OAUTH_TOKEN` 启动的会话中 `/login` 无效的问题——现在会清除该环境 token,让磁盘凭证生效
- 修复「新消息」滚动提示条和 `/plugin` 徽章中文字不可读的问题
- 修复使用 `--dangerously-skip-permissions` 启动时,计划确认对话框错误地提供「auto mode」而非「bypass permissions」的问题
- 修复 agent 类型 hooks 在配置为 `Stop` 或 `SubagentStop` 以外的事件时,报错「Messages are required for agent hooks」的问题
- 修复 agent-hook 校验子 agent 发起的工具调用会重复触发 `prompt` hook 的问题
- 修复 `/fork` 为每个 fork 在磁盘上写入完整父会话的问题——现在只写入指针,读取时再按需水合
- 修复 Alt+K / Alt+X / Alt+^ / Alt+_ 导致键盘输入冻结的问题
- 修复连接到远程会话时覆盖本地 `~/.claude/settings.json` 中 `model` 设置的问题
- 修复粘贴以 `/` 开头的文件路径时,typeahead 显示「No commands match」错误的问题
- 修复对已安装插件再次执行 `plugin install` 时,未重新解析版本错误的依赖的问题
- 修复文件监视器遇到无效路径或文件描述符耗尽时抛出未处理错误的问题
- 修复 JWT 刷新期间 CCR 初始化瞬时抖动导致 Remote Control 会话被归档的问题
- 修复通过 `SendMessage` 恢复的子 agent 未保留其创建时显式指定 `cwd` 的问题
