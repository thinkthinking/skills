# Claude Code 2.1.146（中文版）

- 将 `/simplify` 重命名为 `/code-review`，并支持可选的 effort level（例如 `/code-review high`）
- 自动模式在用户或技能明确依赖 `AskUserQuestion` 时，不再抑制它
- 修复 Windows PowerShell 工具在通过 winget 或 Microsoft Store 安装 `pwsh` 时因 "command line is invalid" 失败的问题（v2.1.124 回归）
- 修复 MCP `resources/list`、`resources/templates/list` 和 `prompts/list` 在分页服务器上丢弃第 1 页之后条目的问题
- 修复 Claude 流式输出时，Windows Terminal 中已附加的后台会话出现全屏闪烁的问题
- 修复自动更新器在更新失败时，状态行不显示当前版本的问题
- 修复 Windows 上移除后台任务 worktree 时会沿 NTFS junction 进入主仓库的问题
- 修复 `/background` 拒绝仅输入过技能或自定义 slash command 的会话的问题
- 修复后台会话会对已选择 "don't ask again" 的工具权限再次弹出确认的问题
- 修复 `/theme` 颜色编辑器和 "New custom theme" 对话框不响应 Esc 的问题
- 修复通过 Agent SDK 运行时，流式会话结束处出现未捕获异常的问题
- 修复 `forceLoginOrgUUID` 和 `forceLoginMethod` managed-settings 策略未对第三方供应商和 API key 会话强制执行的问题
- 修复 GNOME Terminal 右键和中键粘贴无法插入文本的问题
- 修复 `CLAUDE_CODE_SUBAGENT_MODEL` 未转发给多智能体会话中子进程的问题
- 优化自动更新器可靠性：原生版本检查和下载现在会重试瞬时网络失败，而不是立即失败
- 优化大型文件编辑的 diff 渲染性能
