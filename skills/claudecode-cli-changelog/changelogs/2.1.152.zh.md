# Claude Code 2.1.152（中文版）

- `/code-review --fix` 现在会在 review 结束后把 review 发现的问题应用到工作区，并给出复用、简化和效率方面的建议；`/simplify` 现在会调用 `/code-review --fix`
- Skills 和 slash commands 现在可以在 frontmatter 中设置 `disallowed-tools`，在 skill 激活期间从模型可用工具中移除指定工具
- 新增 `/reload-skills` 命令，无需重启会话即可重新扫描 skill 目录
- `SessionStart` hooks 现在可以返回 `reloadSkills: true` 来重新扫描 skill 目录，让 hook 安装的 skills 可在同一会话中使用
- `SessionStart` hooks 现在可以在启动和恢复时通过 `hookSpecificOutput.sessionTitle` 设置会话标题
- 新增 `MessageDisplay` hook event，允许 hooks 在 assistant 消息文本显示时对其进行转换或隐藏
- 新增 `pluginSuggestionMarketplaces` managed setting：管理员可以 allowlist 允许通过上下文感知提示推荐插件的组织 marketplaces
- `claude plugin marketplace remove` 现在接受 `--scope user|project|local`，与 `marketplace add`、`install` 和 `uninstall` 保持对称
- 当主模型未找到时，Claude Code 现在会在当前会话后续请求中切换到你配置的 `--fallback-model`，而不是让每次请求都失败
- Auto mode 不再需要选择性同意
- Vim mode：NORMAL mode 下的 `/` 现在会打开反向历史搜索（类似 Ctrl+R），与 bash/zsh vi-mode 保持一致
- `/usage` 明细现在包含大型会话文件；文件会以 streaming read 方式扫描，因此内存占用保持稳定
- 折叠分组中的 thinking summaries 现在会保持至少 3 秒可读，按 markdown 渲染，并限制为最多 10 行（`Ctrl+O` 可查看完整 thinking）
- 在 fullscreen mode 中，模型 thinking 时的 "Thinking for Ns" 指示器现在会实时递增；如果你中途打断 thinking，它会保留当时的数值
- 简化 Workflow tool 的 inline progress display：实时 agent 数量现在只显示在 prompt 下方的持久 workflow status row 中
- 当后台 agents 或 workflows 仍在运行时，post-response timer 现在会显示 "Waiting for N background agents/workflows to finish"，并在处理完结果后报告累计耗时
- 新增 session entrypoint 作为 OpenTelemetry metric attribute（`app.entrypoint`，通过 `OTEL_METRICS_INCLUDE_ENTRYPOINT=true` 选择启用）
- 修复超长会话中 terminal styling 退化的问题：现在会回收 renderer 的 style pool
- 修复 condensed startup mode 下不会显示 sandbox-enabled warning 的问题：现在会在所有布局中显示
- 修复工具运行期间 loading spinner 显示 "still thinking"/"almost done thinking" 的问题，并在每次工具调用后将 thinking status 重置为 "thinking"
- 修复 focus mode 在没有隐藏活动的轮次中显示虚假的 "N messages hidden" 计数
- 修复点击 expanded tool result 中的链接会折叠该区域而不是打开链接的问题
- 修复 markdown table cell borders 继承 inline code 颜色、wrapped continuation lines 丢失样式，以及空 header cells 在窄终端 stacked layout 中显示标签的问题
- 修复 command 相同但 environment variables 不同的 plugin MCP servers 被错误去重的问题
- 修复 `/doctor` 对引用已移除 marketplaces 或已删除 plugins 的过期 `enabledPlugins` 条目报告 "marketplace not found" 或 "plugin not found" 的问题
- 修复跟踪 git branch 的 plugins 在 plugin registry 重建后悄然停止接收更新的问题
- 修复启用 egress proxy 时，Claude Code Remote sessions 中 remote MCP servers 连接失败的问题
- 修复在会话没有消息或切换到解析后相同的 underlying value 的 effort levels 时，出现 effort-change confirmation dialog 的问题
- 修复在使用 `--bare` 或禁用 attachments 时，Agent tool description 引用一个实际不会交付的 agent list 的问题
- 修复 `claude agents` 中 subagent 已取消后接受过期 permission prompt 会导致 background worker crash 的问题
- 修复当 API 只通过嵌套的 `cache_creation` breakdown 报告 cache writes 时，transcript 和 result usage 中的 `cache_creation_input_tokens` 显示为 0 的问题
- 修复 SDK-hosted sessions 中 Remote Control 已启用时，PushNotification tool 错误报告 "Mobile push not sent (Remote Control inactive)" 的问题
- 修复 model 或 login 切换后历史记录中残留过期 thinking-block signatures 导致会话卡住的问题；现在会主动剥离，并带有 retry safety-net
