# Claude Code 2.1.121（中文版）

- 新增 MCP 服务端配置项 `alwaysLoad`：设为 `true` 时，该服务端的所有工具会跳过工具搜索延迟加载，始终可用
- 新增 `claude plugin prune` 命令，清理因依赖关系自动安装、现已成为孤儿的插件；`plugin uninstall --prune` 会级联清理
- `/skills` 列表新增「输入即筛选」搜索框，技能列表很长时也能秒搜，不用再滚动
- PostToolUse 钩子现在可以通过 `hookSpecificOutput.updatedToolOutput` 替换任意工具的输出（此前仅支持 MCP 工具）
- 全屏模式：向上滚动查看历史输出时，往输入框打字不会再把滚动条强行拉回底部
- 超出终端高度的对话框现在可以滚动了：方向键、PgUp/PgDn、Home/End、鼠标滚轮均可用，全屏与非全屏模式都支持
- 全屏模式下，长 URL 因换行被折成多行时，点击其中任意一行都会打开完整链接
- SDK 与 `claude -p`：`CLAUDE_CODE_FORK_SUBAGENT=1` 现在在非交互式会话中也能生效
- `--dangerously-skip-permissions` 不再对写入 `.claude/skills/`、`.claude/agents/`、`.claude/commands/` 弹出确认
- `/terminal-setup` 现在会顺带打开 iTerm2 的「Applications in terminal may access clipboard」选项，让 `/copy` 在 iTerm2（包括 tmux 内）正常工作
- MCP 服务端启动遇到瞬时错误时，现在会自动重试最多 3 次，而不是直接保持断开状态
- 终端标签页的会话标题现在会按照你配置的 `language` 设置生成
- 上游 URL 相同的 claude.ai 连接器现在会自动去重，不再以重复条目形式出现
- Vertex AI：支持基于 X.509 证书的 Workload Identity Federation（mTLS ADC）
- 升级后启动更快：发布说明启动页移除了「Recent Activity」面板
- LSP 诊断摘要现在支持点击或 ctrl+o 展开，并显示展开提示
- SDK：`mcp_authenticate` 现在支持 `redirectUri`，可用于自定义 scheme 回调以及 claude.ai 连接器
- OpenTelemetry：LLM 请求 span 新增 `stop_reason`、`gen_ai.response.finish_reasons` 与 `user_system_prompt`（受 `OTEL_LOG_USER_PROMPTS` 开关控制）三个字段
- [VSCode] 当未配置 Claude Code 语言时，语音听写现在会遵循 `accessibility.voice.speechLanguage` 设置
- [VSCode] `/context` 现在会打开原生的 token 用量对话框
- 修复一次会话中处理大量图片时内存无限增长（RSS 涨到几个 GB）的问题
- 修复在拥有大量历史会话记录的机器上，`/usage` 会泄漏最多约 2GB 内存的问题
- 修复长任务工具未发出明确进度事件时出现的内存泄漏
- 修复 Claude 启动时所在目录在会话中被删除或移动后，Bash 工具会永久不可用的问题
- 修复外部构建版本中 `--resume` 启动时崩溃的问题
- 修复大会话在异常关闭导致某行 transcript 损坏后，`--resume` 无法恢复的问题——现在会跳过损坏的那一行
- 修复使用 Bedrock application inference profile ARN 时报错 `thinking.type.enabled is not supported` 的问题
- 修复 Microsoft 365 MCP OAuth 因 `prompt` 参数重复或不被支持而失败的问题
- 修复 tmux、GNOME Terminal、Windows Terminal、Konsole 在非全屏模式下按 Ctrl+L 或触发重绘时滚动历史出现重复内容的问题
- 修复 claude.ai 连接器在启动时如果连接器列表请求遇到瞬时鉴权错误，会被静默清空的问题
- 修复远程会话中内置工具的「Always allow」规则在 worker 重启后丢失的问题
- 修复在原生构建下通过 `managed-settings.json` 设置的 `NO_PROXY` 对部分 HTTP 客户端不生效的问题
- 修复托管设置的批准弹窗即使已确认仍会退出会话的问题——现在会应用设置并继续
- 修复 OAuth token 过期后 `/usage` 持续返回「rate limited」的问题——现在会自动刷新 token
- 修复 `settings.json` 中残留的旧版枚举值会让整份设置文件失效的问题
- 修复 no-flicker 模式关闭时 `/usage` 对话框内容被裁切的问题
- 修复全屏渲染器关闭时 `/focus` 报「Unknown command」的问题——现在会提示如何启用
- 修复内置 grep/find/rg shell 包装器在运行的二进制被中途删除时报错的问题——现在会回退到系统已安装的工具
- 优化大型目录树下 Bash 工具中 `find` 的文件描述符峰值占用
