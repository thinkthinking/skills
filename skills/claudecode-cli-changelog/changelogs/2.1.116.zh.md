# Claude Code 2.1.116（中文版）

- 大会话 `/resume` 显著提速（40MB+ 会话最高快 67%），对含大量 dead-fork 条目的会话处理更高效
- 多 stdio MCP 服务配置下启动更快；`resources/templates/list` 现在延迟到首次 `@` 引用时再加载
- VS Code、Cursor 与 Windsurf 终端中全屏模式滚动更顺滑——`/terminal-setup` 现会配置编辑器滚动灵敏度
- 思考 spinner 现在内联显示进度（"still thinking"、"thinking more"、"almost done thinking"），替代原来单独的提示行
- `/config` 搜索现在会匹配选项值（例如搜索 "vim" 可找到 Editor mode 设置）
- `/doctor` 现可在 Claude 响应中随时打开，无需等待当前轮次结束
- `/reload-plugins` 与后台插件自动更新现会从已添加的插件市场中自动安装缺失的插件依赖
- Bash 工具在 `gh` 命令触发 GitHub API 限流时会给出提示，便于 agent 退避而非反复重试
- 设置中的 Usage 标签页现会立即展示 5 小时与每周使用量，使用量接口限流时不再失败
- Agent frontmatter 中的 `hooks:` 现在在通过 `--agent` 以主线程 agent 运行时也会触发
- 斜杠命令菜单在过滤结果为零时显示 "No commands match"，不再整体消失
- 安全：沙箱自动放行不再绕过针对 `/`、`$HOME` 或其他关键系统目录的 `rm`/`rmdir` 危险路径校验
- 修复：终端 UI 中 Devanagari 等印度语系字符渲染导致列对齐错乱的问题
- 修复：iTerm2、Ghostty、kitty、WezTerm、Windows Terminal 等使用 Kitty 键盘协议的终端中 Ctrl+- 无法触发撤销
- 修复：Warp 全屏、kitty、Ghostty、WezTerm 等使用 Kitty 键盘协议的终端中 Cmd+Left/Right 无法跳到行首/行尾
- 修复：通过 `npx`、`bun run` 等包装进程启动 Claude Code 时 Ctrl+Z 卡死终端的问题
- 修复：inline 模式下调整终端大小或大段输出时，scrollback 会重复展示此前会话历史
- 修复：终端高度较短时模态搜索对话框溢出屏幕，导致搜索框与键盘提示被遮挡
- 修复：VS Code 集成终端滚动时出现的零散空白单元与 composer 边框消失问题
- 修复：并行请求在请求建立期间完成时，cache control TTL 顺序引发的偶发 API 400 错误
- 修复：`/branch` 拒绝处理超过 50MB 的会话 transcript
- 修复：`/resume` 在大会话文件上静默显示空会话而不是报告加载错误
- 修复：`/plugin` Installed 页签中，条目同时出现在 Needs attention 或 Favorites 时重复显示
- 修复：会话中途进入 worktree 后 `/update` 与 `/tui` 无法工作
