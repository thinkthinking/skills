# Claude Code 2.1.120（中文版）

- Windows：不再强制要求安装 Git for Windows（Git Bash）——若未安装，Claude Code 会改用 PowerShell 作为 shell 工具
- 新增 `claude ultrareview [target]` 子命令，可在 CI 或脚本中非交互式运行 `/ultrareview`——审查结果输出到标准输出（`--json` 输出原始数据），完成时退出码为 0，失败时为 1
- Skills 内容中现在可以通过 `${CLAUDE_EFFORT}` 引用当前思考预算级别
- 为子进程设置 `AI_AGENT` 环境变量，便于 `gh` 将流量归因到 Claude Code
- 当你已经安装桌面应用或已创建 skills/agents 时，相关的 spinner 推荐提示将不再显示
- 当终端把滚轮事件解析为方向键时，会显示「use PgUp/PgDn to scroll」提示
- 配置了大量未授权的 claude.ai 连接器时，会话启动速度变快
- 自动模式（auto mode）的拒绝提示现在会附上配置文档链接
- `claude plugin validate` 现在允许 `marketplace.json` 顶层包含 `$schema`、`version`、`description`，`plugin.json` 顶层允许 `$schema`
- 自动模式下的自动压缩（auto-compact）现在显示为 `auto`（全小写、无 token 数），不再展示具有误导性的 token 数值
- 修复：在 stdio MCP 工具调用过程中按 Esc 会导致整个服务器连接断开（2.1.105 引入的回归）
- 修复：使用 `claude --resume` 启动后，`/rewind` 等交互式浮层无法响应键盘输入
- 修复：非全屏模式下的终端 scrollback 出现重复（窗口缩放、对话框关闭、长会话场景）
- 修复：`DISABLE_TELEMETRY` / `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` 对 API 和企业用户的用量遥测未生效
- 修复：自动模式下，包含管道符与重定向的多行 bash 命令会被误判为 "Dangerous rm operation" 并触发权限提示
- 修复：全屏模式下长选择菜单超出终端底部被截断——滚动时聚焦项现在会始终保持在可视区域内
- 修复：全屏模式下点击 Write 工具的「+N lines」时输出折叠而非展开
- 修复：slash 命令选择器在输入时跳动；同时改进高亮匹配，仅以蓝色高亮连续匹配的子串
- 修复：当某个 marketplace 条目使用了未知的 source 格式时，`/plugin` 整个市场加载失败——现在该条目仍会显示，但安装时会提示你升级
- [VSCode] `/usage` 现在会打开原生的 Account & Usage 对话框，而不是返回纯文本的会话成本
- [VSCode] 语音听写现在遵循 `~/.claude/settings.json` 中的 `language` 设置
- 修复：Bash 工具中的 `find` 在大目录树上耗尽文件描述符，导致整机崩溃（macOS/Linux 原生构建）
