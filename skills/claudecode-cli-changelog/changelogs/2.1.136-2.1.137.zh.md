# Claude Code 2.1.137 + 2.1.136（中文版）

这份合并版 changelog 包含两个连续更新：`2.1.137` 是 VS Code Windows 热修复，`2.1.136` 是一次覆盖稳定性、MCP、终端交互与插件体验的综合修复版本。

## 2.1.137

- [VSCode] 修复扩展在 Windows 上无法激活的问题

## 2.1.136

- 新增 `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL`，用于为通过 OpenTelemetry 采集反馈的企业重新启用会话质量调查
- 新增 `settings.autoMode.hard_deny`，用于 auto mode 分类器规则，可无条件阻止请求，不受用户意图或允许例外影响
- 修复 VS Code 扩展、JetBrains 插件和 Agent SDK 中，配置在 `.mcp.json`、插件和 claude.ai connectors 里的 MCP servers 在 `/clear` 后静默消失的问题
- 修复一个罕见登录循环：并发写入凭据可能覆盖刚轮换的 OAuth token，导致用户被迫重新登录
- 修复多个服务器并发刷新时 MCP OAuth refresh tokens 丢失的问题；使用多个远程 MCP servers 的用户不应再需要每天重新认证
- 修复 extended thinking 在 tool call 之后输出 redacted thinking block 时触发 API error (400) 的问题
- 修复项目路径包含下划线时，`--resume` / `--continue` 找不到会话的问题
- 修复存在匹配的 `Edit(...)` allow rule 时，plan mode 未阻止文件写入的问题
- WSL2：当 xclip/wl-paste 无法读取图片数据时，现在可通过 PowerShell fallback 从 Windows 剪贴板粘贴图片
- 修复插件 `Stop`/`UserPromptSubmit` hooks 在缓存清理删除仍被运行中会话使用的版本时失败的问题
- 优化 slash command dialogs 的视觉一致性：统一 footer hints、dialog spacing 和 arrow-key 样式；dialog frame 现在会在加载时立即出现，而不是加载后突然弹出
- 修复 bash 命令输出和 markdown code blocks 中颜色出现在错误位置的问题
- 修复 ReasonML diffs 在 word-diff 边界渲染出损坏的 "undefined" 文本伪影的问题
- 修复移除 worktree 后，worktree exit dialog 对错误目录提示未提交文件的问题
- 修复小型非 git 目录中，`@` file picker 无法匹配会话中途创建文件的问题
- 修复目录超过 100 个条目时，`@`-mention file picker 找不到文件的问题
- 修复 fullscreen mode 下失败的 tool calls 在输出被截断时无法点击展开的问题
- 修复在具有持久 extended-key modes 的终端中使用 Ctrl+G 打开外部编辑器后，Backspace 和 Ctrl+Backspace 被对调的问题
- 修复 `/usage` weekly reset 显示一天中的具体时间而不是日历日期的问题
- 修复欢迎横幅省略号在 CJK 终端上导致列溢出的问题
- 修复 session history 包含 malformed input fields 的 tool calls 时 `/insights` 崩溃的问题
- 修复 tool 的 collapsibility classification 在会话中途变化时导致 renderer 崩溃的问题
- 修复 `plugin.json` 中的 `skills` 条目会隐藏插件默认 `skills/` 目录的问题；现在列出文件路径会显示错误，而不是静默失败
- 修复 IDE shell-integration lock files 未遵守 `CLAUDE_CONFIG_DIR` 的问题
- 修复流式输出期间复制 terminal output 时带有尾随空白的问题
- 修复插件 uninstall 和 enable/disable 未按大小写不敏感方式匹配 slugs 的问题
- 修复 surrogate-pair strings 的 tool error truncation marker 显示负数计数的问题
- 修复 `/resume` 或 `/clear` 后，来自 `CLAUDE_ENV_FILE` SessionStart hooks 的 env vars 变陈旧的问题
- 修复 `/branch` 在传入粘贴的多行名称时保存多行 session title 的问题
- 修复列边界处换行文本第二行出现多余前导空格的问题
- 修复 Esc 无法关闭 `/install-github-app`、`/desktop`、`/resume` 和 `/web-setup` dialogs 的问题
- 修复 `/doctor` MCP schema errors 未标明缺失字段或未显示 source file path 的问题
- 修复 Bash permission prompts 显示内部 parser diagnostic，而不是用户可读解释的问题
- 修复带空格的插件 slash commands（例如 `/myplugin review`）无法解析到 namespaced form 的问题
- 修复 `AskUserQuestion` 在以数组形式提供 multi-select answers 时丢弃答案的问题
- 修复 `/clear <name>` 未为 `/resume` 标注已清除会话的问题
- 修复 `CronList` output 缺少 qualifiers 和 scheduled prompt 的问题
- 修复 fullscreen mode 下 "Jump to bottom" overlay 在 CJK 字符上留下颜色伪影的问题
- 修复宽 markdown tables 在流式输出时会在 terminal scrollback 中留下陈旧的带边框渲染的问题
- 修复带 pasted-text placeholder 的长 prompt 被自动截断时，粘贴文本被静默丢弃的问题
- 修复 `/release-notes` 在 changelog refresh 失败后卡在旧版本的问题
- 修复 `/mcp` server list 在服务器数量超过终端可显示范围时无法滚动的问题
- 修复首次 slash command 后，输入中途的 slash command autocomplete 不工作的问题
- 修复在 `autoScrollEnabled: false` 时，滚动到底部会重新启用 auto-follow 的问题
- 修复空输入时按 Enter 会自动提交 prompt suggestions，而不是要求使用 Tab 或方向键接受的问题
- 修复 keyboard shortcut hints 未反映 `keybindings.json` 中重新绑定按键的问题
- 修复 `/settings` 中确认语言变更后按 Escape 会回退该变更的问题
- 修复 `/terminal-setup` 只在精确匹配名称时出现在 autocomplete 中，而不是支持部分前缀匹配的问题
- 修复 `AskUserQuestion` dialog 上的 "Chat about this" 会擦除 question text 的问题
- 修复 MCP tool results 在服务器返回 content blocks 时不可见的问题
- 优化 `--worktree` 与现有或陈旧 worktree 冲突时的错误信息
- 变更 plugin marketplace 的 removal key 为 `d`（与其他位置的 delete 一致），不再使用会与 retry 冲突的 `r`
