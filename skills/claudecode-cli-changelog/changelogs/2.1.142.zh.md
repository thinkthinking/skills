# Claude Code 2.1.142（中文版）

- 新增 `claude agents` flags：`--add-dir`、`--settings`、`--mcp-config`、`--plugin-dir`、`--permission-mode`、`--model`、`--effort` 和 `--dangerously-skip-permissions`，用于配置派发的后台会话
- Fast mode 现在默认使用 Opus 4.7（之前为 Opus 4.6）。设置 `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1` 可将 fast mode 固定到 Opus 4.6
- 只有根目录 `SKILL.md`、且没有 `skills/` 子目录的插件现在会作为一个 skill 展示
- `/plugin` 详情面板和 `claude plugin details` 现在会显示插件提供的 LSP servers
- `/web-setup` 在替换现有 GitHub App 连接前会发出警告
- 修复 `MCP_TOOL_TIMEOUT` 未提升 remote HTTP 和 SSE MCP servers 的单请求 fetch 超时时间，导致 tool calls 无论配置值如何都会被限制在 60 秒的问题
- 修复后台会话无法识别已存在的 git worktrees，导致 Edit 被阻塞，而 EnterWorktree 又拒绝创建重复 worktree 的问题
- 修复 macOS sleep/wake 后后台会话消失且 daemon 重新连接失败的问题：daemon 现在会检测时钟跳变，而不是把它当作已流逝的 idle time
- 修复 binary 升级后（例如 `brew upgrade`）daemon 未干净退出，导致派发的 agents 在已删除路径上 crash-loop 的问题
- 修复 Claude-in-Chrome extension 已连接但没有共享标签页时，后台 agents crash-loop 的问题
- 修复在 attached 的 `claude agents` 会话中点击链接的问题：attached 状态下后台 worker 的 headless browser shim 不再生效
- 修复 `claude agents` 中 "v to open in editor" 使用 daemon 默认编辑器，而不是 shell 的 `$EDITOR`/`$VISUAL` 的问题
- 修复 Windows 上使用 network-drive working directories 时 `claude agents` deadlock 的问题；Ctrl+C 现在可在启动期间生效
- 修复从 Apple Terminal 或其他仅支持 256-color 的终端 attach 到 `claude agents` 会话时出现 background-color bleed 的问题
- 修复 `claude --bg --dangerously-skip-permissions` 在 retire/wake 后未持久保留的问题
- 修复首条消息是链接时，session titles 从 URL 派生的问题
- 修复 remote clients 发出的冗余 `set_model` requests 会向 transcript 注入重复 `/model` breadcrumbs 的问题
- 修复使用 `skills: ["./"]` 的插件误报 "path escapes plugin directory" 的问题
- 修复缺少 installation metadata 时，plugin cache cleanup 会删除 active plugin version directory 的问题
- 修复 `/plugin` browse pane 对新发布插件显示 "0 installs" 的问题
- 修复 plugin advisories 未列出每个会遮蔽默认文件夹的 `plugin.json` key 的问题
- 优化 reactive compaction：首次 summarize attempt 现在会基于原始请求的 overflow size 初始化，避免一次接近 full-context 的无效重试
- 优化 hook configuration error：为 `SessionStart`/`Setup`/`SubagentStart` 配置 prompt- 或 agent-type hook 时，现在会显示清晰的 "use a command-type hook instead" 错误
- 移除 Usage Policy refusal messages 中过期的 `/model claude-sonnet-4-20250514` 建议
