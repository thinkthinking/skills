# Claude Code 2.1.126（中文版）

- 当 `ANTHROPIC_BASE_URL` 指向兼容 Anthropic 协议的网关时，`/model` 选择器会从该网关的 `/v1/models` 接口列出可用模型
- 新增 `claude project purge [path]` 命令，可删除项目对应的所有 Claude Code 状态（会话记录、任务、文件历史、配置项），支持 `--dry-run`、`-y/--yes`、`-i/--interactive` 和 `--all` 选项
- `--dangerously-skip-permissions` 现在会跳过对 `.claude/`、`.git/`、`.vscode/`、Shell 配置文件等此前受保护路径的写入提示（灾难性删除命令仍会作为兜底进行确认）
- 当浏览器回调无法访问 localhost（WSL2、SSH、容器场景）时，`claude auth login` 现支持把 OAuth 授权码粘贴到终端完成登录
- `claude_code.skill_activated` OpenTelemetry 事件现也会在用户手动输入斜杠命令时触发，并新增 `invocation_trigger` 属性（取值 `"user-slash"`、`"claude-proactive"`、`"nested-skill"`）
- Auto 模式：当权限检查卡住时，spinner 会变红，避免被误认为是工具仍在执行
- 由宿主托管的部署（`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST`）在使用 Bedrock/Vertex/Foundry 时不再自动关闭埋点
- Windows：现可识别通过 Microsoft Store、未配置 PATH 的 MSI 或 `.NET global tool` 安装的 PowerShell 7
- Windows：启用 PowerShell 工具后，Claude 会把 PowerShell 视为主 Shell，而不再默认使用 Bash
- Read 工具：移除了逐文件触发的恶意软件评估提示——之前会让旧模型误拒读取并输出「这不是恶意软件」之类的多余说明
- **安全：** 修复在更高优先级的托管设置源缺失 `sandbox` 配置块时，`allowManagedDomainsOnly` / `allowManagedReadPathsOnly` 被忽略的问题
- 修复粘贴大于 2000px 的图片会让会话崩溃的问题——粘贴时图片会自动降采样，历史中过大的图片会被自动移除并重试请求
- 修复「OAuth not allowed for organization」错误时仍弹出登录界面的问题——现会提示用户联系管理员
- 修复在慢速或代理网络、纯 IPv6 devcontainer 以及浏览器回调无法访问 localhost 时 OAuth 登录会超时的问题
- 修复一种罕见竞态：并发写入凭据可能清空有效的 OAuth refresh token
- 修复 API 重试倒计时停在「0s」而不会逐步递减的问题
- 修复 Mac 从睡眠中唤醒、且请求正在进行时出现「Stream idle timeout」错误
- 修复后台会话和远程会话在模型长时间「思考」时被错误中止为「Stream idle timeout」的问题
- 修复在多个空轮次后助手「思考」结束却不输出内容的卡死问题
- 修复 Cursor 与 VS Code 1.92–1.104 内置终端中触控板滚动过快的问题
- 修复因手动添加的服务器卡在 needs-auth 状态而压制 claude.ai MCP 连接器显示的问题
- 修复 Windows 在无闪烁（no-flicker）模式下日/韩/中文显示为乱码的问题
- 修复 `Ctrl+L` 会清空输入框的问题——现仅强制重绘屏幕，与 readline 行为一致
- 修复使用 `context: fork` 的 skill 与其他子代理在首轮无法使用 WebSearch、WebFetch 等延迟加载工具的问题
- 修复使用 `--channels` 启动的交互式会话中 plan 模式工具不可用的问题
- 修复 `/plugin` 卸载后状态显示为「Enabled」而非「Uninstalled」的问题
- 当 linter 一次性修改大量文件时，限制了文件变更提醒的总长度
- 修复 `/remote-control` 重试显示卡在「connecting…」的问题——现在每次重试都会展示结果
- 修复远程连接初次连接失败时通知不显示错误原因的问题
- Windows：剪贴板写入不再把复制内容暴露在进程命令行参数中（避免被 EDR/SIEM 采集），同时修复 >22KB 选区无法进入剪贴板的问题
- PowerShell 工具：不再把裸 `--`（如 `git diff -- file`）误判为 `--%` 停止解析符
- 修复 Agent SDK 在模型于并行工具调用批次中返回非法工具名时挂起的问题
