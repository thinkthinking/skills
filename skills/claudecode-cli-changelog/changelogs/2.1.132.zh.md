# Claude Code 2.1.132（中文版）

- 新增 `CLAUDE_CODE_SESSION_ID` 环境变量到 Bash 工具子进程环境，与传递给 hooks 的 `session_id` 保持一致。
- 新增 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 环境变量，可选择退出全屏 alternate-screen 渲染器，并将对话保留在终端原生滚动历史中。
- 新增 Ctrl+V 图片粘贴从剪贴板读取时的“Pasting…”底部提示。
- 修复外部 SIGINT（例如 IDE 停止按钮、`kill -INT`）不会执行优雅关闭的问题：现在会恢复终端模式，并打印 `--resume` 提示，而不是突然退出。
- 修复原生构建下终端关闭或 SSH 在会话中断开时出现未捕获异常的问题。
- 修复工具错误截断切分 emoji 时，`--resume` 因 `no low surrogate in string` 失败的问题；加载时会清理已损坏的历史会话。
- 修复使用 `-p --continue`/`--resume` 恢复 plan-mode 会话时 `--permission-mode` 标志被忽略，以及同一会话内 `ExitPlanMode` 后没有重新应用 plan mode 的问题。
- 修复笔记本睡眠/唤醒或 Ctrl+Z/`fg` 后，全屏模式显示空白屏幕，直到下一次按键或流式输出才恢复的问题。
- 修复 Indic 组合字或 ZWJ emoji 跨行换行时，Ctrl+E/A/K/U/方向键会让光标落在字素中间的问题。
- 修复 vim 操作符会破坏包含分解式（NFD）重音字符的文本的问题。
- 修复粘贴以 `/` 开头的文本时，输入被静默吞掉或触发未知命令回复的问题。
- 修复焦点事件或鼠标追踪报告与 bracketed paste 交错时，粘贴会把零散转义序列写入提示词的问题。
- 修复由于上游 xterm.js bug，Cursor 和 VS Code 1.92–1.104 中鼠标滚轮滚动过快的问题。
- 修复 JetBrains IDE 2025.2 终端中的滚轮处理问题（错误箭头键、方向相反事件、失控加速）。
- 修复 Linux/X11 上 `/usage` 使用 Ctrl+S 将统计截图复制到剪贴板时卡住的问题。
- 修复 `/terminal-setup` 在 Windows Terminal 中显示矛盾错误的问题：Shift+Enter 在其中已原生支持。
- 修复 `/effort` 选择器没有反映 `CLAUDE_CODE_EFFORT_LEVEL` 环境变量覆盖的问题。
- 修复 `/status` 对部分用户显示错误默认模型的问题。
- 修复 slash command 自动补全弹窗被限制在约 3–5 个可见命令，而没有随终端高度扩展的问题。
- 修复 statusline 的 `context_window` token 计数反映累计会话总量，而不是当前上下文使用量的问题。
- 修复 macOS 终端未启用“Option as Meta”时（iTerm2、Terminal.app 默认设置），Alt+T（thinking toggle）无法工作的问题。
- 修复从 `claude agents` 重新打开后台会话后，Windows 上键盘输入失效的问题。
- 修复 stdio MCP server 向 stdout 写入非协议数据时出现无上限内存增长（10GB+ RSS）的问题。
- 修复 MCP server 已连接但 `tools/list` 失败时静默显示 0 个工具的问题：现在会重试一次，并在 `/mcp` 中显示“connected · tools fetch failed”。
- 修复未授权的 claude.ai MCP connectors 显示为“failed”而不是“needs auth”，以及 headless `-p` 模式会重试非临时 4xx 连接失败的问题。
- 优化 slash command 对话框以及 `/login`、`/upgrade`、`/extra-usage` 对话框间距的视觉一致性。
- 更新 `/tui fullscreen` 启动横幅，用于说明更多渲染器收益（更低内存占用、鼠标支持、选中自动复制）。
- 修复设置 `ENABLE_PROMPT_CACHING_1H` 时 Bedrock 和 Vertex 出现 400 错误的问题。
