# Claude Code 2.1.149 + 2.1.150（中文版）

## 2.1.150

- 内部基础设施改进（无用户可见变更）

## 2.1.149

- `/usage` 现在会按类别展示是什么在消耗你的 limits usage，包括 skills、subagents、plugins 和每个 MCP server 的 cost
- `/diff` detail view 现在支持用键盘滚动（arrows、`j`/`k`、`PgUp`/`PgDn`、`Space`、`Home`/`End`）
- Markdown output 现在会将 GFM task list checkboxes（`- [ ] todo` / `- [x] done`）渲染为复选框，而不是普通 bullets
- Enterprise：新增 `allowAllClaudeAiMcps` managed setting，用于在加载 `managed-mcp.json` 的同时加载 claude.ai cloud MCP connectors
- 修复 PowerShell permission bypass：内置 `cd` functions（`cd..`、`cd\`、`cd~`、`X:`）会在未被检测到的情况下改变 working directory，导致后续命令可以读取 workspace 之外的内容
- 修复 git worktrees 中 sandbox write allowlist 覆盖整个主仓库 root，而不是只覆盖共享 `.git` directory 的问题（同时拒绝 `hooks/` 和 `config`）
- 修复 PowerShell prefix/wildcard allow rules（例如 `PowerShell(dotnet.exe build *)`）不会预先批准 native executables 和 scripts 的问题
- 修复 permission-analysis gap：parser 在 `cd`/`pushd`/`popd` 过程中会信任 `PWD`/`OLDPWD`/`DIRSTACK` 的陈旧 variable-tracking values
- 修复 Bash tool 中的 `find` 在大型目录树上耗尽 macOS system file/vnode table 并导致 host 崩溃的问题
- 修复 managed-settings approval dialog 在启动时接受后会让 terminal 冻结的问题
- 修复当 working tree 没有真实变更时，`/ultraplan` 和 remote session creation 会因 "Could not capture uncommitted changes" 失败的问题
- 修复 `otelHeadersHelper` 在 script path 包含空格时静默失败的问题；helper failures 现在会在 `/doctor` 和 debug log 中报告
- 修复 thinking spinner 在 tool calls 之间以及进入新的 thinking bursts 时仍保持 amber 的问题
- 修复 collapsed Bash output 对包含许多短行的输出报告错误 hidden-line count 的问题
- 修复 slash-command argument-hint 在 hint 溢出 input box 时会截断末尾已输入字符的问题
- 修复 Tab 补全 frontmatter `name:` 与目录 basename 不同的 skill 后，argument-hint 和 progressive arg suggestions 不出现的问题
- 修复 status bar 显示用户基线 `/effort` 设置，而不是 skill/agent `effort:` frontmatter 实际应用的 effort level 的问题
- 修复 Ctrl+O transcript view 在打开瞬间冻结，而不是继续 tailing new messages 的问题
- 修复编辑 recalled prompt-history entry 后，再用 arrow keys 继续上下导航会丢失编辑内容的问题
- 修复切换无关设置时，`/config` exit summary 会报告 auto-compact 和 theme 的 phantom changes 的问题
- 修复 cached session-meta files 缺少 optional fields 时，`/insights` 崩溃的问题
- 修复缺少 input 的 malformed PowerShell 和 History tool calls 在 transcript collapsing 中被误分类为 reads 的问题
- 修复从 claude.ai 或 Claude mobile app 重命名 Remote Control session 后，本地 session name 未为 `claude --resume` 更新的问题
- 修复刚提交的 prompt 可能在 up-arrow history 中出现两次的 race
- 修复 fullscreen mode 中点击 "Jump to bottom" pill 后不会立即关闭它的问题
- 优化 `/feedback` reports：现在会包含 context compaction 之前的 conversation，让长会话早期问题更容易 triage
