# Claude Code 2.1.117（中文版）

- 外部构建现在可以通过设置 `CLAUDE_CODE_FORK_SUBAGENT=1` 启用分叉子代理（Forked subagents）
- Agent frontmatter 中的 `mcpServers` 现在会在通过 `--agent` 启动主线程代理会话时被加载
- 优化 `/model`：模型选择在重启后仍然保留，即使项目固定了其他模型；启动头部现在会提示当前激活的模型是否来自项目或受管设置的固定配置
- `/resume` 命令在重新读取陈旧的大会话前，现在会提供总结选项，与 `--resume` 的现有行为保持一致
- 当同时配置本地和 claude.ai MCP 服务器时，启动速度更快（现在默认并发连接)
- 对已安装的插件执行 `plugin install` 现在会补装缺失的依赖，而不是在"已安装"处停止
- 插件依赖错误现在会提示"未安装"并附带安装提示，`claude plugin marketplace add` 现在会从已配置的市场自动解析缺失依赖
- 受管设置中的 `blockedMarketplaces` 和 `strictKnownMarketplaces` 现在会在插件安装、更新、刷新以及自动更新时强制生效
- Advisor Tool（实验特性）：对话框现在带有"experimental"标签、了解更多链接，以及启用时的启动通知；会话不再因每次提示和 `/compact` 时报"Advisor tool result content could not be processed"错误而卡死
- `cleanupPeriodDays` 的保留清理现在也会清理 `~/.claude/tasks/`、`~/.claude/shell-snapshots/` 和 `~/.claude/backups/`
- OpenTelemetry：斜杠命令的 `user_prompt` 事件现在包含 `command_name` 和 `command_source`；`cost.usage`、`token.usage`、`api_request` 和 `api_error` 在模型支持 effort 时会带上 `effort` 属性。自定义/MCP 命令名默认脱敏，除非设置 `OTEL_LOG_TOOL_DETAILS=1`
- macOS 和 Linux 原生构建：`Glob` 和 `Grep` 工具被替换为通过 Bash 工具调用的内嵌 `bfs` 和 `ugrep`——搜索更快，无需独立的工具往返（Windows 和 npm 安装版不受影响）
- Windows：对每个进程缓存 `where.exe` 可执行文件查询结果，加快子进程启动
- Pro/Max 订阅用户在 Opus 4.6 和 Sonnet 4.6 上的默认 effort 等级改为 `high`（此前为 `medium`）
- 修复 Plain-CLI OAuth 会话在 access token 中途过期时报"Please run /login"并崩溃的问题——现在会在 401 时响应式刷新 token
- 修复 `WebFetch` 处理超大 HTML 页面时卡死的问题，在 HTML 转 markdown 前先截断输入
- 修复代理返回 HTTP 204 No Content 时崩溃的问题——现在会报出清晰错误，而不是 `TypeError`
- 修复通过 `CLAUDE_CODE_OAUTH_TOKEN` 环境变量启动且 token 过期时 `/login` 无效的问题
- 修复输入框撤销（`Ctrl+_`）在刚输入后立即按下无效、且每次撤销都跳过一步状态的问题
- 修复在 Bun 下运行时，远程 API 请求不尊重 `NO_PROXY` 的问题
- 修复慢连接下按键名以合并文本到达时，偶发错误触发 escape/return 的问题
- 修复 SDK 中 `reload_plugins` 串行重连所有用户 MCP 服务器的问题
- 修复 Bedrock application-inference-profile 请求在后端为 Opus 4.7 且禁用 thinking 时报 400 错误的问题
- 修复 print/SDK 模式下服务器在会话中途完成连接时，MCP `elicitation/create` 请求被自动取消的问题
- 修复子代理使用与主代理不同的模型时，错误地将文件读取标记为恶意软件警告的问题
- 修复存在后台任务时的空闲重渲染循环，减少 Linux 下的内存增长
- [VSCode] 修复配置多个大型市场时"Manage Plugins"面板崩溃的问题
- 修复 Opus 4.7 会话 `/context` 百分比虚高、过早触发自动压缩的问题——Claude Code 之前按 200K 上下文窗口计算，而非 Opus 4.7 原生的 1M
