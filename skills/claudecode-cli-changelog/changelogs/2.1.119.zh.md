# Claude Code 2.1.119（中文版）

- `/config` 设置项（主题、编辑器模式、verbose 等）现已持久化到 `~/.claude/settings.json`，并遵循 project/local/policy 的覆盖优先级
- 新增 `prUrlTemplate` 设置，让页脚的 PR 徽章指向自定义代码审阅地址，而不再强制跳转 github.com
- 新增 `CLAUDE_CODE_HIDE_CWD` 环境变量，可在启动 logo 中隐藏当前工作目录
- `--from-pr` 现已支持 GitLab merge-request、Bitbucket pull-request 以及 GitHub Enterprise 的 PR 链接
- `--print` 模式现在会尊重 agent 的 `tools:` 和 `disallowedTools:` 前置元数据,与交互模式行为一致
- `--agent <name>` 现在会尊重内置 agent 定义中的 `permissionMode`
- PowerShell 工具命令现已可在权限模式下自动批准,与 Bash 行为一致
- Hooks：`PostToolUse` 与 `PostToolUseFailure` 的输入现在包含 `duration_ms`（工具执行耗时,不含权限提示与 PreToolUse hook 时间）
- 子代理（subagent）与 SDK MCP 服务器的重新配置,现在并行连接而非串行连接
- 被其他插件版本约束锁定的插件,现在会自动更新到满足约束的最高 git tag
- Vim 模式：INSERT 态下的 Esc 不再把队列中的消息拉回输入框；再按一次 Esc 才会中断
- 斜杠命令建议现在会高亮匹配到查询的字符
- 斜杠命令选择器现在会把较长的描述换行到第二行,而不再截断
- 输出中的 `owner/repo#N` 简写链接现在使用你 git remote 的 host,而不再一律指向 github.com
- 安全：`blockedMarketplaces` 现已正确执行 `hostPattern` 与 `pathPattern` 条目
- OpenTelemetry：`tool_result` 与 `tool_decision` 事件现在包含 `tool_use_id`；`tool_result` 还额外包含 `tool_input_size_bytes`
- 状态栏：stdin JSON 现在包含 `effort.level` 与 `thinking.enabled`
- 修复粘贴 CRLF 内容（Windows 剪贴板、Xcode 控制台）时,每行之间被插入额外空行的问题
- 修复在使用 kitty 键盘协议序列的终端中,bracketed paste 里多行粘贴丢失换行的问题
- 修复当 Bash 工具因权限被拒时,原生 macOS/Linux 构建上 Glob 和 Grep 工具消失的问题
- 修复全屏模式下向上滚动时,每次工具结束都会被强制弹回底部的问题
- 修复当 MCP 服务器的 OAuth discovery 返回非 JSON 响应体时,HTTP 连接失败并报 "Invalid OAuth error response" 的问题
- 修复 Rewind 浮层对含图片附件的消息显示 "(no prompt)" 的问题
- 修复 auto 模式以冲突的 "Execute immediately" 指令覆盖 plan 模式的问题
- 修复不返回响应体的异步 `PostToolUse` hook 会向会话记录写入空条目的问题
- 修复当子代理任务通知在队列中残留时,spinner 不停止的问题
- Vertex AI 默认关闭 Tool search,避免 unsupported beta header 错误（可通过 `ENABLE_TOOL_SEARCH` 开启）
- 修复在斜杠命令中使用绝对路径时,`@`-file Tab 补全会替换掉整个 prompt 的问题
- 修复在 macOS Terminal.app 通过 Docker 或 SSH 启动时,prompt 上出现多余 `p` 字符的问题
- 修复 HTTP/SSE/WebSocket MCP 服务器 `headers` 中的 `${ENV_VAR}` 占位符,请求前未被替换的问题
- 修复通过 `--client-secret` 存储的 MCP OAuth client secret,在服务器要求 `client_secret_post` 的 token exchange 中未被发送的问题
- 修复 `/skills` 中按 Enter 键直接关闭对话框,而不是把 `/<skill-name>` 预填到 prompt 的问题
- 修复 `/agents` 详情页把子代理不可用的内置工具错误标记为 "Unrecognized" 的问题
- 修复当插件缓存不完整时,Windows 上插件提供的 MCP 服务器无法启动的问题
- 修复 `/export` 显示当前默认模型,而不是会话实际使用的模型的问题
- 修复 verbose 输出设置重启后不持久化的问题
- 修复 `/usage` 进度条与其 "Resets …" 标签重叠的问题
- 修复当 `${user_config.*}` 引用了一个留空的可选字段时,插件 MCP 服务器失败的问题
- 修复句末带数字的列表项,数字被换行到单独一行的问题
- 修复进入 plan 模式时,`/plan` 和 `/plan open` 不作用于已有 plan 的问题
- 修复在自动压缩（auto-compaction）之前调用的 skill,会在下一条用户消息时被重复执行的问题
- 修复 `/reload-plugins` 和 `/doctor` 对已禁用插件报告加载错误的问题
- 修复 `isolation: "worktree"` 模式的 Agent 工具复用历史会话残留 worktree 的问题
- 修复已禁用的 MCP 服务器在 `/status` 中被显示为 "failed" 的问题
- 修复 `TaskList` 返回任务顺序为任意文件系统顺序,而非按 ID 排序的问题
- 修复当 `gh` 输出中的 PR 标题包含 "rate limit" 字样时,错误地提示 "GitHub API rate limit exceeded" 的问题
- 修复 SDK/bridge 的 `read_file` 在文件增长时未正确执行大小上限的问题
- 修复在 git worktree 中工作时 PR 未关联到会话的问题
- 修复 `/doctor` 对被更高优先级作用域覆盖的 MCP 服务器条目发出警告的问题
- Windows：移除了误报的 "Windows requires 'cmd /c' wrapper" MCP 配置警告
- [VSCode] 修复 macOS 上麦克风权限提示弹出期间,语音听写的首次录音输出空内容的问题
