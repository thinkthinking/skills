# Claude Code 2.1.157-2.1.158（中文版）

## 2.1.158

- Auto 模式现已在 Bedrock、Vertex 和 Foundry 上支持 Opus 4.7 与 Opus 4.8。通过设置 `CLAUDE_CODE_ENABLE_AUTO_MODE=1` 启用

## 2.1.157

- `.claude/skills` 目录下的插件现在会自动加载，无需 marketplace
- 新增 `claude plugin init <name>`，可在 `.claude/skills` 中脚手架生成新插件
- 为 `/plugin` 参数新增自动补全：子命令、已安装的插件名，以及来自已知 marketplace 的插件
- `claude agents`：派发会话现在会读取 `settings.json` 中的 `agent` 字段，并可用 `--agent <name>` 覆盖
- `EnterWorktree` 现在支持在会话中途切换 Claude 托管的 worktree
- 当设置 `OTEL_LOG_TOOL_DETAILS=1` 时，`tool_decision` 遥测事件现在会包含 `tool_parameters`（bash 命令、MCP/skill 名称）
- Claude 托管的 worktree 在 agent 完成后现在会保持解锁状态，以便 `git worktree remove`/`prune` 清理它们
- 修复了通过粘贴、MCP 或对话框附加的无法处理的图片（零字节、损坏）会导致请求崩溃，而非降级为文本占位符的问题
- 修复了在桌面应用、IDE 扩展或 SDK 中使用 auto 模式和 bypass-permissions 模式时仍出现沙盒网络权限提示的问题
- 修复了 `claude agents` 已完成会话在仍有闲置子 agent 驻留、或泄漏了后台 shell 时无法退役的问题
- 修复了 `claude agents` 中按 Esc 无法取消缓慢的「opening…」、导致列表无响应的问题
- 修复了 `.claude/worktrees/` 下的后台 agent worktree 在 30 天任务保留清理后被遗留的问题
- 修复了睡眠/唤醒后重新接入的后台会话未告知模型正确日期的问题
- 修复了在 tmux 开启 `set-clipboard on` 时，`claude agents` 中的选中即复制无法送达系统剪贴板的问题（2.1.153 引入的回归）
- 修复了 `--resume` 未报告上一个 Claude Code 进程退出时仍在运行的后台子 agent 的问题
- 修复了 `--resume` 会话选择器在全屏模式下退出后仍把内容残留在终端上的问题
- 修复了 `--worktree` 与 `--worktree --tmux` 返回到规范仓库根目录、而非当前关联 worktree 的问题
- 修复了当所选模型已是同系列最新时，`/model` 选择器仍错误显示「Newer version available」提示的问题；固定模型行现在显示模型描述而非其原始 ID
- 修复了全屏模式下进行中消息文本里出现字面 markdown 标记（反引号、星号）的问题
- 修复了启动时确认 managed-settings 安全对话框后终端冻结的问题
- 修复了终端 UI 重绘后偶发在回滚区出现重复行的问题
- 修复了在 VS Code、Cursor 和 Windsurf 集成终端中右键粘贴会重复剪贴板内容的问题
- WSL：修复了图片粘贴（`alt+v` 快捷键）、Windows 11 上的截图粘贴，并新增了从 Windows 资源管理器拖入图片的支持
- 通过消除冗余的消息渲染重算，优化了长对话和恢复会话的性能
- `/terminal-setup` 现在会在 VS Code/Cursor/Windsurf 集成终端中禁用 GPU 加速，以避免文本渲染乱码
- 「Feature of the Week」积分领取状态现在以通知形式出现在状态区域，而非提示框上方的一行
- `claude agents`：派发输入框中的斜杠命令自动补全现在支持子串匹配
- 移除了「bash commands will be sandboxed」启动横幅——沙盒状态仍会在 `/status` 中以及命令被拦截时显示
- 移除了「/ide for …」启动提示气泡
- [IDE] 修复了在后台子 agent 运行时点击 Stop 实际未停止的问题
- [VSCode] 修复了 Opus 4.8 上 fast 模式指示器不显示的问题
- 在 workflow 触发关键词后立即按退格键，现在会取消该 workflow 请求（与 alt+w 相同），而不是删除一个字符
- 在 /config 中新增「Workflow keyword trigger」设置，可阻止 prompt 中的「workflow」一词触发动态 workflow
