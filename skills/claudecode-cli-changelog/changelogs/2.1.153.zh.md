# Claude Code 2.1.153（中文版）

- 新增 `skipLfs` 选项，可用于 `github`/`git` 插件市场源，在 clone 和 update 时跳过 Git LFS 下载。
- 当 npm 全局安装无法自动更新时，Claude Code 现在会显示一次性提示；`/doctor` 会列出修复方式。
- 状态栏命令现在会收到 `COLUMNS` 和 `LINES` 环境变量，方便脚本按终端宽度调整输出。
- `claude agents`：dispatch 输入框的自动补全现在会建议原生 slash commands 和 bundled skills，不再只建议项目 skills。
- `claude agents`：PR 列现在会针对单个 PR 显示 `PR #N`，多个 PR 显示 `N PRs`。
- `claude doctor` 现在会显示上一次更新尝试的结果。
- 将 MCP servers 和 connectors 启动时各自的 “needs authentication” 通知合并为一条消息。
- macOS：background agents 现在会在 Privacy & Security 中显示为 “Claude Code”，并且升级后会保留权限授权。
- 修复没有可选 GET SSE stream 的 stateful MCP servers 在 `tools/list` 上反复重连的问题（v2.1.147 回归）。
- 修复一个回归问题：custom API gateway 可能收到用户的 Anthropic OAuth credential，而不是 gateway 自己的 token。
- 修复 subagent（Agent tool）frontmatter MCP servers 忽略 `--strict-mcp-config`、`--bare`、remote mode、enterprise managed MCP config，以及 managed-settings MCP server allow/deny policies 的问题。
- `--strict-mcp-config` 不再从显式传入的 agent definitions（`--agents` / SDK `agents`）中移除 inline `mcpServers`，被阻止的 subagent MCP servers 现在也会显示可见警告。
- 修复 Windows PowerShell installer 在实际安装失败时仍报告 “Installation complete!” 的问题。
- 修复 npm 安装场景下 `claude update` 安装 latest version，而不是已配置 release channel 版本的问题。
- 修复在存储了大量 session 的机器上按 transcript file path 恢复 session 时内存占用过高（多个 GB）的问题。
- 修复升级后 `claude agents` 和 `claude --bg` 仍运行在 binary-takeover 支持之前启动的旧 daemon 上的问题。
- 修复 stream-json mode 下 stdin 关闭但没有 EOF 时 CLI 可能无法退出，并留下 stale session marker 的 hang 问题。
- 修复 Claude 响应中格式错误的 `file://` links 在终端里不可点击的问题。
- 修复 `claude --help` 在宽度小于 92 列的终端上输出不换行的问题。
- 修复 MCP tool progress notifications 不会在 collapsed tool view 中渲染的问题。
- 修复带有 `subagent_type: 'claude'` 的 `Agent` tool 运行在未文档化的临时 worktree 中，可能静默丢弃写入 gitignored 路径的输出的问题。
- Claude 正在响应时执行 `/bg`，现在会在 background session 中继续该响应，而不是丢弃它。
- 修复 task 运行时 background sessions 中 `/btw` keyboard shortcuts 失去响应的问题。
- 修复 background sessions 将临时文件写入 `$CLAUDE_JOB_DIR` 会触发 “sensitive file” 权限提示的问题。
- 修复恢复工作目录已被删除的 background agent 时显示截断 stack trace，而不是清晰错误信息的问题。
- 修复 `EnterWorktree` 在 background sessions 中不会立即可用的问题（此前需要先使用 `ToolSearch`）。
- 修复 iTerm2/Terminal.app 中的 `cmd+k` 不会重绘已 attached background sessions 的问题。
- 修复 Windows 上 attached background sessions 中 IME candidate window 出现在屏幕底部，而不是输入光标旁边的问题。
- 修复 background agent 渲染文件 diff 后，从仅支持 256 色的终端 attach 时出现 background-color bleed 的问题。
- 修复在 tmux 内 attached background session 中 `/copy` 和 copy-on-select 静默无法更新系统剪贴板的问题。
- 修复启用 Remote Control 时打开 `claude agents`，退出后在 Code tab 留下 zombie session entries 的问题。
- 修复 background sessions 中 `/rename` 不会立即更新 session banner 的问题。
- 修复 Windows update rollback：如果 Windows update 失败，Claude Code 现在会通过复制恢复原始可执行文件，并告知你如何恢复。
- [VSCode] 修复 Windows 上 VS Code 关闭时 Claude Code processes 无法干净关闭，导致误报 “unclean exit” 以及遗留 orphaned MCP servers 的问题。
- `/model` 现在会将你的选择保存为新 session 的默认模型（与 IDE 一致）。在 picker 中按 `s` 可仅为当前 session 切换模型。
- 如果你自定义了 `modelPicker:setAsDefault` keybinding，请在 keybindings.json 中将其重命名为 `modelPicker:thisSessionOnly`（`d` 操作已被 `s` 替换）。
