# Claude Code 2.1.113（中文版）

- 变更：CLI 改为通过各平台 optional dependency 调起原生 Claude Code 二进制，替代此前打包的 JavaScript 版本
- 新增：`sandbox.network.deniedDomains` 配置项，即便 `allowedDomains` 通配符放开，也可精确拦截指定域名
- 全屏模式：在选区延伸到可视区域外时，`Shift+↑/↓` 现在会滚动视口
- 多行输入下，`Ctrl+A`、`Ctrl+E` 现在按逻辑行跳转到行首/行尾，与 readline 行为一致
- Windows：`Ctrl+Backspace` 现在会删除前一个单词
- 回复和 bash 输出中的长 URL，即便换行也保持可点击（需终端支持 OSC 8 超链接）
- 优化 `/loop`：按 Esc 可取消待触发的 wakeup；wakeup 触发时显示为「Claude resuming /loop wakeup」，语义更清晰
- `/extra-usage` 现在可从 Remote Control（移动端/Web 端）客户端使用
- Remote Control 客户端现在可查询 `@`-file 的自动补全建议
- 优化 `/ultrareview`：并行化检查，启动更快；启动弹窗新增 diffstat；加入启动动画状态
- 子 agent 中途卡住的流，现在会在 10 分钟后以明确错误终止，不再静默挂起
- Bash 工具：首行是注释的多行命令，现在会在 transcript 里完整展示命令，封堵 UI 伪造攻击路径
- `cd <当前目录> && git …`：当 `cd` 实为空操作时，不再触发权限弹窗
- 安全：macOS 下 `/private/{etc,var,tmp,home}` 路径在 `Bash(rm:*)` allow 规则中被视为高危删除目标
- 安全：Bash deny 规则现在能匹配被 `env` / `sudo` / `watch` / `ionice` / `setsid` 等 exec 包装器包裹的命令
- 安全：`Bash(find:*)` allow 规则不再自动放行 `find -exec` / `-delete`
- 修复 MCP 并发调用超时处理：原先一次工具调用的消息可能静默解除另一次调用的 watchdog
- 修复 `Cmd-Backspace` / `Ctrl+U` 行首删除行为被破坏的问题
- 修复 markdown 表格中，单元格里含有管道符的 inline 代码片段会破坏表格渲染的问题
- 修复：在输入框里正编辑未发送文本时，session recap 会自动触发的问题
- 修复 `/copy` 的「Full response」选项在复制到 GitHub、Notion、Slack 时 markdown 表格列未对齐的问题
- 修复：查看运行中的子 agent 时输入的消息，会被隐藏不进入 transcript、且归因到父 AI 的问题
- 修复 Bash `dangerouslyDisableSandbox` 在沙箱外运行命令却未弹出权限提示的问题
- 修复 `/effort auto` 的确认文案——现在显示「Effort level set to max」，与状态栏标签一致
- 修复「copied N chars」toast 对 emoji 及其他多码元字符计数偏大的问题
- 修复 Windows 下 `/insights` 因 `EBUSY` 崩溃的问题
- 修复退出确认弹窗把一次性定时任务误标为「recurring」的问题——现在展示倒计时
- 修复全屏模式下 slash / `@` 补全菜单未贴合输入框边框的问题
- 修复 `CLAUDE_CODE_EXTRA_BODY` 的 `output_config.effort` 在子 agent 调用不支持 effort 的模型、以及调用 Vertex AI 时触发 400 的问题
- 修复设置 `NO_COLOR` 时 prompt 光标消失的问题
- 修复 `ToolSearch` 排序问题：粘贴的 MCP 工具名现在会优先匹配到真正的工具，而不是描述相似的同类工具
- 修复恢复的长上下文 session 在 compact 时报「Extra usage is required for long context requests」的问题
- 修复 `plugin install` 在依赖版本与已安装插件冲突时仍然成功的问题——现在会报 `range-conflict`
- 修复「Refine with Ultraplan」未在 transcript 里展示 remote session URL 的问题
- 修复 SDK 图像 content block 处理失败时整个 session 崩溃的问题——现在会降级为文本占位符
- 修复 Remote Control session 未流式传输子 agent transcript 的问题
- 修复 Claude Code 退出时 Remote Control session 未归档的问题
- 修复通过 Bedrock Application Inference Profile ARN 调用 Opus 4.7 时返回 `thinking.type.enabled is not supported` 400 错误的问题
