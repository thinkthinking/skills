# Claude Code 2.1.147 + 2.1.148（中文版）

## 2.1.148

- 修复部分用户的 Bash tool 在每个命令上都返回 exit code 127 的问题（2.1.147 引入的回归）

## 2.1.147

- 固定的后台会话（`claude agents` 中的 `Ctrl+T`）现在会在 idle 时保持存活，会原地重启以应用 Claude Code 更新，并且在内存压力下只会在非固定会话之后被回收
- 将 `/simplify` 重命名为 `/code-review`。它现在会按所选 effort level 报告正确性 bug（例如 `/code-review high`）；传入 `--comment` 可将发现作为 GitHub PR inline comments 发布。旧的清理和修复行为已移除
- 优化自动更新器：重试瞬时网络失败，失败时报告具体错误类别和 OS error codes，并在更新失败时显示当前版本
- 优化大型文件编辑的 diff 渲染性能
- Prompt history 不再记录连续重复条目：用 arrow-up 调出 prompt 并再次提交时，不会再新增一份副本
- 修复企业登录限制（`forceLoginOrgUUID` 和 `forceLoginMethod` managed-settings）未对第三方供应商和 API key 会话强制执行的问题
- 修复 `!` command output 中的 `&` 显示为 `&amp;` 的问题，该问题会破坏从 `gcloud auth login` 等命令复制 URL
- 修复 headless/SDK mode 中未知 slash commands 静默无反应的问题：现在会显示错误消息
- 修复非 fullscreen mode 的小终端上，`/help` 渲染损坏的 tab header 且每页只显示一个命令的问题
- 修复 shell snapshot 丢弃名称以单个下划线开头的用户函数，导致引用它们的 aliases 损坏的问题
- 修复在 `tools:` frontmatter 中声明多个 `Agent(...)` 类型的 plugin agents 会丢弃除最后一项外所有条目的问题
- 修复 `PowerShell(git push*)` 这类 hook `if` 条件永远不匹配的问题，此前只有 `PowerShell(*)` 可用
- 修复 PowerShell tool 对依赖默认 formatter 的命令丢弃输出的问题
- 修复：在 Windows 上，对 PowerShell script invocation 选择 "Yes, and don't ask again" 现在会写入一条后续运行能实际匹配的规则
- 修复 Windows 上通过 winget 或 Microsoft Store 安装 `pwsh` 时，PowerShell tool 会因 exit code 1 失败的问题
- 修复 `/effort` 打开时 slider 位于错误级别的问题：现在会从你的当前 effort 开始
- 修复分页 MCP servers 丢弃第 1 页之后 resources、templates 和 prompts 的问题
- 修复 Claude 流式输出时，Windows Terminal 中已附加的后台会话出现全屏闪烁的问题
- 修复：在 Windows 上，移除后台任务 worktree 不再沿 NTFS junction 进入主仓库
- 修复 `/background` 拒绝仅输入过技能或自定义 slash command 的会话的问题
- 修复当用户或技能明确依赖 `AskUserQuestion` 时，auto mode 会抑制它的问题；auto-mode classifier 现在会将用户回答视为 intent signal
- 修复 `/theme` 的 "New custom theme" 和 color editor dialogs 不响应 Esc 的问题
- 修复通过 Agent SDK 运行时，流式会话结束处出现未捕获异常的问题
- 修复 Windows 上等待滚动稳定时偶发挂起的问题
- 修复 Windows 上当后台会话结果包含宽字符（CJK）时，agent view list 出现陈旧和重复行的问题
- 修复粘贴文本会以不可读的 `[Pasted text #N]` 占位符交给 agents，而不是传递实际内容的问题
- 修复当 plugin manifest 列出的 paths 与其默认目录重叠时，`claude plugin details` 和 `/plugin` 中的 plugin component counts 会翻倍的问题
- 修复后台会话会对已选择 "don't ask again" 的工具权限再次弹出确认的问题
- 修复 GNOME Terminal 右键和中键粘贴无法插入文本的问题
- 修复 `CLAUDE_CODE_SUBAGENT_MODEL` 未应用到 agent teams 生成的 teammate processes 的问题
- 修复 slash commands 后跟 tab 或 newline 时会被视为未知命令的问题
- 修复 `/plugin`、`/status`、`/mobile`、`/sandbox` 和 `/permissions` menus 中的若干间距和布局问题
- 修复被剥离的 images 会促使模型反复重新读取已不存在 media 的问题
