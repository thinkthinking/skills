# Claude Code 2.1.139（中文版）

- 新增 agent view（Research Preview）：用一个列表展示所有 Claude Code 会话，包括正在运行、等待你处理，或已经完成的会话。运行 `claude agents` 即可开始使用。参见 https://code.claude.com/docs/en/agent-view
- 新增 `/goal` 命令：设置完成条件后，Claude 会跨多个回合持续工作，直到条件满足。支持 interactive、`-p` 和 Remote Control。会以浮层面板实时显示耗时、回合数和 token 数
- 新增 `/scroll-speed` 命令，可通过实时预览调节鼠标滚轮滚动速度
- 新增 `claude plugin details <name>`，用于展示插件的组件清单和预计每会话 token 成本
- 新增 transcript view 导航：`?` 查看快捷键，`{`/`}` 在用户 prompt 之间跳转，`v` 切换快捷键面板
- 新增 hook `args: string[]` 字段（exec form），可不经过 shell 直接启动命令，因此路径占位符无需再做引号转义
- 新增 hook `continueOnBlock` 配置项，适用于 `PostToolUse`：设为 `true` 后，会把 hook 的拒绝原因反馈给 Claude 并继续当前回合
- MCP stdio servers 现在会在环境变量中收到 `CLAUDE_PROJECT_DIR`，与 hooks 保持一致。Plugin configs 可在命令中引用 `${CLAUDE_PROJECT_DIR}`
- Compaction prompt 现在会要求模型保留敏感的用户指令
- `/mcp` Reconnect 现在无需重启即可读取 `.mcp.json` 修改，并会在重连失败时显示 HTTP 状态和 URL
- `/context all` 的按技能 token 估算现在会考虑模型 tokenizer，并显示四舍五入后的数值
- `claude plugin install <name>@<marketplace>` 现在会自动刷新 marketplace 并重试，然后才报告插件未找到
- `/plugin` 的已安装插件详情现在会清晰显示 hook event 名称和 MCP server 名称
- `/context` 现在会为 plugin-sourced skills 显示提供该技能的 plugin 名称
- Remote MCP server 在瞬时失败时的重连重试现在对所有用户启用
- 来自 subagents 的 API 请求现在会携带 `x-claude-code-agent-id` / `x-claude-code-parent-agent-id` headers，并且 `claude_code.llm_request` OTEL spans 会包含 `agent_id` / `parent_agent_id` attributes
- 当设置了 `ANTHROPIC_API_KEY` / `apiKeyHelper` / `ANTHROPIC_AUTH_TOKEN` 时，即使也存在 Claude.ai 登录，Remote Control、`/schedule`、claude.ai MCP connectors 和通知偏好现在也会被禁用。若要使用这些功能，请取消设置 API key
- 修复过期凭证和 `forceRemoteSettingsRefresh` policy setting 导致 `claude auth login`/`logout`/`status` 死锁且无法恢复的问题
- 修复 `autoAllowBashIfSandboxed` 不会自动批准带有 `$VAR` 和 `$(cmd)` 等 shell expansions 命令的问题
- 修复 hook 写入 terminal 时可能破坏屏幕上交互式 prompt 的问题；hooks 现在运行时不会访问 terminal
- 修复 HTTP/SSE MCP server 流式输出非协议数据时内存无限增长的问题；response bodies 现在限制为每个 SSE frame 16 MB
- 修复 `Skill(name *)` permission rules；通配符形式现在会像 `Bash(ls *)` 一样按前缀匹配
- 修复 settings hot-reload 无法检测符号链接形式的 `~/.claude/settings.json` 修改的问题
- 修复当 marketplace key 与 manifest name 不一致时 plugin details 加载失败的问题
- 修复 `/model` picker 的 "Default" 行无法反映 `ANTHROPIC_DEFAULT_OPUS_MODEL`/`ANTHROPIC_DEFAULT_SONNET_MODEL` overrides 的问题
- 修复响应完成 5 分钟后出现误报 "stream idle timeout" 的问题，原因是 stream cancellation 时未清除 watchdog timer
- 修复配置 10+ MCP servers 且 cache directory 不可写时静默 `exit 1` 的问题；错误信息现在会包含底层原因
- 修复 dialog 中 tab 名称、列表指针和 select 行上出现输入光标闪烁的问题
- 修复 transcript view 在鼠标点击后字母快捷键失效的问题
- 修复 Bash-mode 上箭头历史记录会重复第一条并覆盖正在输入草稿的问题
- 修复粘贴或拖放多张图片时只插入最后一张的问题
- 修复深色主题下超链接使用难以阅读的深海军蓝色的问题；现在会随当前主题自适应
- 修复对模型设置为 `opus` alias 的第三方用户，model picker 显示多余 "Current model" 行的问题
- 修复 PAYG 3P providers 上的 legacy Opus picker 条目会解析到与默认条目相同模型的问题
- 修复 Cursor 和 VS Code 1.92–1.104 中鼠标滚轮滚动速度问题；trackpad 现在会稳定滚动，鼠标滚轮保持约每格 3 行
- 修复附加到后台会话时，Windows Terminal 和 VS Code 中的滚动行为问题
- 修复已断开服务器的 MCP resources 仍残留在 `@server:` autocomplete 中的问题
- 修复双文件 diff snippets 多报一个被截断行数的问题
- 修复 Grep results 不会将 Windows drive-letter paths 相对化，以及 count mode 对单文件路径统计错误的问题
- 修复 CJK/emoji 因 visual cell width 计算错误导致 border-embedded text 溢出的问题
- 修复 fuzzy-match highlighting 会把 emoji 和 astral-plane characters 从字符对中间拆开的问题
- 修复 skill argument names 包含 regex metacharacters 时 argument substitution 失效的问题
- 修复 ProgressBar 会把接近满格的 fractional cell 渲染成完整 block 的问题
- 修复当最后一个 subscriber 离开但 fetch 仍在进行时，task polling 和 `fs.watch` 被重新拉起的问题
- 修复当 manifest name 与 source identifier 不一致时，plugin dependency resolution 会留下过期计数的问题
- 修复 session 中存在不可解析 timestamp 时，Insights Time-of-Day chart 出现偏移的问题
- 修复只使用 cmd/super/win modifier 的 keybindings 被标记为不可解析的问题
- 修复 `--print` mode 下未发出 `claude_code.active_time.total` OpenTelemetry metric 的问题
- 修复 `claude plugin update` 不保留 marketplace 内跨 plugin symlinks 的问题
- [VSCode] 按 Cmd/Ctrl+Shift+T 可重新打开最近关闭的 session tab，并可通过 `claudeCode.enableReopenClosedSessionShortcut` 配置
