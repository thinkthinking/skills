# Claude Code 2.1.141（中文版）

- 新增 hook JSON 输出字段 `terminalSequence`，让 hooks 可以在没有控制终端的情况下发出桌面通知、窗口标题和铃声。
- 新增 `CLAUDE_CODE_PLUGIN_PREFER_HTTPS`，用于通过 HTTPS 而不是 SSH 克隆 GitHub 插件源，适用于没有 GitHub SSH key 的环境。
- 新增 `ANTHROPIC_WORKSPACE_ID` 环境变量，用于 workload identity federation：当 federation 规则覆盖多个 workspace 时，将签发的 token 限定到指定 workspace。
- 新增 `claude agents --cwd <path>`，用于将会话列表限定到某个目录。
- `/feedback` 现在可以包含最近会话（过去 24 小时或 7 天），用于跨越当前会话的问题。
- Rewind 菜单：新增 “Summarize up to here”，可压缩更早的上下文，同时保留最近轮次完整。
- Auto mode 权限对话框现在会说明提示是否由 `permissions.ask` 规则触发。
- 当已连接 IDE 时，恢复文件编辑权限提示中的 “view diff in your IDE” 选项。
- 通过 `/bg` 或 `←←` 启动的后台 agents 现在会保留当前权限模式，而不是回退到默认值。
- `claude agents`：完成工作但仍留下后台 shell 运行的 agents 现在会移至 Completed，而不是停留在 Working。
- 优化长时间思考期间的 spinner 反馈：10 秒后 spinner 会变为琥珀色，以提示 Claude 仍在工作。
- 优化插件菜单导航：`→`/Tab 切换标签页，`↑` 移动到标签栏，fullscreen mode 下标签标题和搜索框可点击。
- 修复在未设置 `ANTHROPIC_SMALL_FAST_MODEL` override 时，后台 side-queries 在 Bedrock/Vertex/Foundry/gateway 上发送不可用 Haiku model ID 的问题；现在会回退到 main-loop model。
- 修复 Windows 上 `claude daemon status` 和 `/doctor` 在 daemon pipe key file 被锁定或不可读时抛错的问题；现在会显示底层错误，而不是不透明的失败。
- 修复通过会追加 flags 的 wrapper 启动时，`claude agents` 显示 agent-type 列表而不是 dashboard 的问题。
- 修复 `claude agents` 打开崩溃会话时，如果工作目录已被删除会触发冗余 dispatches 的问题。
- 修复自定义 `ANTHROPIC_BASE_URL` gateway 上的后台任务无法自动命名的问题；当未配置 Haiku model 时，namer 现在会使用 main model。
- 修复一个会话中的 `/model` 静默改变其他并发会话 autocompact threshold 的问题。
- 修复工具权限提示打开时切换权限模式，在新设置已允许该工具的情况下不会自动关闭提示的问题。
- 修复权限/对话框提示打开时按 Enter 也会提交输入框文本的问题。
- 修复 `EnterWorktree` 切换工作目录后，hooks 收到不存在的 `transcript_path` 的问题。
- 修复带单元格换行的 markdown 表格回退到纵向 key-value 布局而不是渲染为带边框网格的问题（2.1.136 回归）。
- 修复被取消的 prompts 自动恢复到输入框时会从 Up-arrow history 中移除的问题，避免重复条目。
- 修复在任何响应前用 Ctrl+C/Esc 取消的 prompts 从 Up-arrow history 中丢失的问题。
- 修复 vim INSERT/VISUAL mode 下 Ctrl+C 无法中断正在运行的 turn 的问题。
- 修复当 `enter` 被重新绑定为 `chat:newline` 时，替代 `chat:submit` keybindings（如 `meta+enter`、`ctrl+enter`）不生效的问题。
- 修复配置 output style 后 prompt suggestions 被静默禁用的问题。
- 修复 turn-completion messages 中不遵循 `spinnerVerbs` 设置的问题。
- 修复 AskUserQuestion popup 隐藏前面聊天内容最后一行的问题。
- 修复 Web Search 出错时状态显示 “Did 0 searches” 的问题。
- 修复 multi-line statusline 输出中，当任意行超过终端宽度时会丢行或破坏行内容的问题。
- 修复 light-ansi theme 在浅色背景上用不可见白色显示 diff context lines 的问题；现在改为黑色。
- 修复 error overlay 输出 minified bundle source，导致原始错误消息被隐藏的问题。
- 修复输入反馈调查评分数字后按 Enter 会将其作为聊天消息提交，而不是作为评分提交的问题。
- 修复在 agent panel 中对选中的 subagent 按 `x` 会输入到 prompt，而不是停止该 agent 的问题。
- 修复 session title 会在用户首次 prompt 前从 plugin monitor notifications 派生的问题。
- 修复折叠的 read/search group 下，“Allowed by PermissionRequest hook” 会对每个 tool call 重复一次的问题。
- 修复 `/tui` 静默丢弃正在运行的后台 shells 和 subagents 的问题；现在会拒绝并要求等待它们完成。
- 修复 Bedrock、Vertex、Foundry 和其他 third-party providers 上 welcome banner 显示 “API Usage Billing” 的问题；现在显示 provider name。
- 修复 fullscreen mode 的短终端中 `/mcp` server list 不保持焦点 server 可见的问题。
- 修复 `/feedback` bundles 中的 redaction 对 session IDs 等带引号值生成无效 JSON 的问题。
- 修复 desktop 和 third-party provider sessions 错误继承 host managed-settings 中 `apiKeyHelper`/`ANTHROPIC_AUTH_TOKEN` 的问题。
- 修复 logger 初始化前触发的早期 analytics events 被静默丢弃的问题。
- 修复当插件 marketplace `ref` 在上游不再存在且同时 pinned `sha` 时，`claude plugin install` 失败的问题。
- 修复 plugin details pane 对通过 `.mcp.json` 声明 MCP servers 的插件显示 0 个 MCP servers 的问题。
- 修复带未设置 config variables 的 plugin MCP servers 显示通用连接失败，而不是带修复提示的 “config issue” 消息的问题；格式错误的 `.mcp.json` 条目也不会再丢弃其他 MCP servers。
- 修复使用 POSIX shell parameter expansions（如 `${var%pattern}`）的 MCP server configs 被错误标记为缺失环境变量的问题。
- 修复 MCP HTTP/SSE servers 连接返回 403 时显示为 “failed” 而不是 “needs auth” 的问题。
- 修复 optional server-events stream 重连失败时 remote MCP servers 不必要断开的问题；tool calls 会继续通过 POST 执行。
- 修复 worker session token 在会话中轮换时，Remote Control MCP connectors 全部返回 401 的问题。
- 修复服务器拒绝过期 token 时 Remote Control 会自动重新注册 trusted device，而不是循环进入 `/login`。
- 修复在启用 beta tracing 的 SDK/headless mode 下，早期 OTel spans 可能被静默丢弃的竞态问题。
- 修复自定义 `voice:pushToTalk` keybindings 和 `"space": null` unbinds 被静默忽略的问题。
- 修复 Windows Alt+V image paste 在剪贴板包含截图时仍报告 “no image found” 的问题。
- 修复 Linux 上同时安装 glibc 和 musl platform packages 时出现 SDK “Claude Code native binary not found” 的问题。
- Bedrock：配置后 `awsCredentialExport` 现在始终会运行，不再因 ambient AWS credentials 已解析而跳过，修复跨账号访问鉴权。
- [VSCode] 修复 in-chat mic 在麦克风只产生静音时没有反馈的问题；现在会显示 “No audio detected”。
- [VSCode] Voice mode：WSL error 现在会建议 WSLg 用户安装 `sox libsox-fmt-pulse`。
- `claude agents`：当预热的后台 worker 不健康时，启动会话不再失败；现在会回退到 fresh launch。
- `claude agents` 不再显示从后台化 fresh REPL 遗留的空 placeholder sessions，并且在没有其他 agents 时通过 ← 进入会显示 onboarding text。
- `←` 遗留的空闲后台 sessions 现在会在 5 分钟后由 daemon 自动清理。
